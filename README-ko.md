## 이야기 — 왜 EurekAI인가?

**EurekAI**는 [Mistral AI Worldwide Hackathon](https://luma.com/mistralhack-online) ([공식 사이트](https://worldwide-hackathon.mistral.ai/)) (2026년 3월) 기간에 탄생했습니다. 주제가 하나 필요했는데, 아이디어는 아주 현실적인 것에서 나왔습니다. 저는 딸과 함께 정기적으로 시험 대비 공부를 하는데, AI를 활용하면 이 과정을 더 재미있고 인터랙티브하게 만들 수 있겠다고 생각했습니다.

목표는 **어떤 입력이든** — 수업 사진, 복사해 붙여 넣은 텍스트, 음성 녹음, 웹 검색 — 을 **복습 노트, 플래시카드, 퀴즈, 팟캐스트, 빈칸 채우기, 일러스트 등**으로 바꾸는 것입니다. 모두 Mistral AI의 프랑스 모델로 구동되므로, 프랑스어권 학생들에게 자연스럽게 잘 맞는 솔루션입니다.

[초기 프로토타입](https://github.com/jls42/worldwide-hackathon.mistral.ai)은 해커톤 48시간 동안 Mistral 서비스 중심의 개념 증명으로 설계되었으며, 이미 동작했지만 제한적이었습니다. 그 이후 EurekAI는 진짜 프로젝트로 발전했습니다: 빈칸 채우기, 연습 문제 내비게이션, 웹 스크래핑, 설정 가능한 부모 통제, 심층 코드 리뷰 등 많은 기능이 추가되었습니다. 코드 전체는 AI가 생성하며 — 주로 [Claude Code](https://code.claude.com/)를 사용하고, 일부는 [Codex](https://openai.com/codex/)와 [Gemini CLI](https://geminicli.com/)로 기여했습니다.

## 자세히 보기 — 기능

### 다중 모달 입력

EurekAI는 4가지 유형의 소스를 지원하며, 프로필별로 모더레이션이 적용됩니다(어린이와 청소년은 기본 활성화) :

- **파일 가져오기** — JPG, PNG 또는 PDF 파일을 Mistral OCR로 처리합니다 — **기본 OCR 3 (`mistral-ocr-2512`)**, **옵션 OCR 4 (`mistral-ocr-4-0`)** 는 설정에서 선택 가능(더 좋은 품질이지만 비용은 2배) — 인쇄 텍스트, 표, 필기체용입니다. 또는 텍스트 파일(TXT, MD)을 직접 가져올 수 있습니다. 다중 파일 업로드는 **업로드 세션** 시스템을 사용합니다: 파일별 개별 진행률, 실패한 파일만 재시도하고 다른 파일은 다시 보내지 않으며, 완료되면 세션을 닫을 수 있습니다. OCR은 평균 **신뢰도 점수**(`average`, `[0,1]`로 클램프되고, Mistral이 반환한 `averagePageConfidenceScore`를 기준으로 계산됨)를 노출하며, UI에서는 `high` / `medium` / `low` 등급 배지로 표시됩니다(임계값 ~0.9 / ~0.7) — 품질이 낮은 스캔일 때는 차단하지 않고 경고만 표시합니다.
- **자유 텍스트** — 어떤 내용이든 입력하거나 붙여 넣으세요. 모더레이션이 활성화되어 있으면 저장 전에 검토됩니다.
- **음성 입력** — 브라우저에서 오디오를 녹음합니다. `voxtral-mini-latest`가 전사합니다. `language="fr"` 매개변수는 인식률을 최적화합니다.
- **웹 / URL** — 콘텐츠를 직접 스크래핑하기 위해 하나 이상의 URL을 붙여 넣거나(Readability + Lightpanda, JS 페이지용), Agent Mistral을 통해 웹 검색을 위해 키워드를 입력할 수 있습니다. 하나의 입력칸이 두 가지를 모두 받으며 — URL과 키워드는 자동으로 분리되고, 각 결과는 독립적인 소스를 만듭니다.

### AI 콘텐츠 생성

생성되는 학습 자료는 7가지 유형입니다.

| 생성기 | 모델 | 출력 |
|---|---|---|
| **복습 노트** | `mistral-large-latest` | 제목, 요약, 핵심 포인트, 어휘, 인용문, 일화 |
| **플래시카드** | `mistral-large-latest` | 소스 참조가 포함된 Q/A 카드(개수 설정 가능) |
| **객관식 퀴즈** | `mistral-large-latest` | 객관식 문제, 설명, 적응형 복습(개수 설정 가능) |
| **빈칸 채우기** | `mistral-large-latest` | 힌트와 관대한 검증(Levenshtein)이 있는 완성 문장 |
| **팟캐스트** | `mistral-large-latest` + Voxtral TTS | 2인 스크립트 → MP3 오디오 |
| **일러스트** | Agent `mistral-large-latest` | `image_generation` 도구를 통한 교육용 이미지 |
| **음성 퀴즈** | `mistral-large-latest` + Voxtral TTS + STT | TTS 질문 → STT 응답 → AI 검증 |

### 채팅형 AI 튜터

수업 문서에 완전히 접근할 수 있는 대화형 튜터입니다.

- `mistral-large-latest`를 사용합니다
- **도구 호출**: 대화 중에 복습 노트, 플래시카드, 퀴즈 또는 빈칸 채우기를 생성할 수 있습니다
- 수업당 50개의 메시지 기록
- 프로필에 대해 활성화된 경우 콘텐츠 모더레이션

### 자동 라우터

라우터는 `mistral-small-latest`를 사용해 소스 콘텐츠를 분석하고, 사용 가능한 7개 생성기 중 가장 적절한 항목을 제안합니다. 인터페이스는 실시간 진행률을 보여 줍니다: 먼저 분석 단계가 나오고, 그다음 각 개별 생성이 진행되며 필요하면 취소할 수 있습니다.

### 적응형 학습

- **퀴즈 통계**: 문항별 시도 횟수와 정확도 추적
- **퀴즈 복습**: 약한 개념을 겨냥한 새로운 문제 5~10개 생성
- **지시문 감지**: 복습 지시("나는 ...를 알면 내 수업을 안다")를 감지하고 호환되는 텍스트 생성기(노트, 플래시카드, 퀴즈, 빈칸 채우기)에서 우선 처리

### 보안 및 부모 통제

- **4개 연령 그룹**: 어린이(≤10세), 청소년(11-15), 학생(16-25), 성인(26+)
- **콘텐츠 모더레이션**: `mistral-moderation-latest`과 10개 사용 가능 카테고리, 어린이/청소년은 기본적으로 5개가 차단됨(`sexual`, `hate_and_discrimination`, `violence_and_threats`, `selfharm`, `jailbreaking`). 카테고리는 설정에서 프로필별로 사용자 지정 가능.
- **부모 PIN**: SHA-256 해시, 15세 미만 프로필에 필요합니다. 프로덕션 배포에서는 느린 해시와 솔트(Argon2id, bcrypt)를 사용하는 것이 좋습니다.
- **채팅 제한**: 16세 미만은 기본적으로 AI 채팅이 비활성화되며, 부모가 활성화할 수 있습니다

### 다중 프로필 시스템

- 이름, 나이, 아바타, 언어 기본 설정이 있는 여러 프로필
- **프로필별 음성** (`Profile.mistralVoices?: { host, guest }`) — 각 아이는 팟캐스트/음성 퀴즈용 자신의 음성 쌍을 가질 수 있습니다
- **프로필별 테마** (`Profile.theme: 'dark' | 'light'`) — 프로필 변경 시 자동 전환되며 백엔드에 유지됩니다
- `profileId`를 통해 프로필과 연결된 프로젝트
- 연쇄 삭제: 프로필을 삭제하면 그 프로필의 모든 프로젝트가 삭제됩니다

### API 비용 추적

모든 Mistral 호출(chat, OCR, STT, TTS, 모더레이션, 에이전트)은 사용자에게 **투명한** € 비용 추정을 제공하도록 계측되어 있습니다 — 청구에 대한 놀라움이 없습니다.

- **기준 데이터 소스**: `helpers/pricing.ts` — 모델 접두사별 `MODEL_PRICING`(예: `mistral-large` → 입력 0.5 €/M tokens, 출력 1.5 €/M tokens), 주기적 재스크래핑을 위한 Mistral 문서 URL이 포함된 `PRICING_SOURCES`
- **지원 단위**: `tokens`, `characters`(TTS), `pages`(OCR), `audio-seconds`(STT) — `helpers/cost-calc.ts`가 변환을 담당
- **계측 체인**: `helpers/tracked-client.ts`(Mistral 클라이언트 래핑) → `helpers/usage-context.ts`(AsyncLocalStorage) → `helpers/cost-calc.ts` → `helpers/cost-persist.ts` → `helpers/cost-middleware.ts`(HTTP 응답에 주입)
- **UI**: 생성별 비용 배지(`src/partials/cost-badge-gen.html`), 소스별 배지(`cost-badge-src.html`), 대시보드의 누적 총합(`Project.totalCost`)
- **엔드포인트**: `/generate/*` 및 `/sources/*` 응답은 반환된 객체(Generation / Source)에 `estimatedCost`, `usage`, `costBreakdown`를 포함하도록 장식합니다. `POST /generate/auto/route`는 라우팅 전용 비용을 위한 `costDelta: number` 필드를 추가합니다. `GET /projects/:pid`는 `totalCost`( `costLog[]`에서 계산된 합계 )와 전체 기록이 포함된 프로젝트를 반환합니다

### 다중 공급자 TTS 및 사용자 지정 음성

- **Mistral Voxtral TTS** : `voxtral-mini-tts-latest`, 100% Mistral 음성 합성, 추가 키 불필요
- **사용자 지정 음성**: 부모는 Mistral Voices API를 통해(오디오 샘플에서) 자신만의 음성을 만들고 호스트/게스트 역할에 할당할 수 있습니다 — 그러면 팟캐스트와 음성 퀴즈가 부모의 목소리로 재생되어 아이에게 더욱 몰입감 있는 경험을 제공합니다
- 구성 가능한 두 개의 음성 역할: **호스트**(주요 내레이터)와 **게스트**(팟캐스트의 두 번째 목소리)
- Mistral의 전체 음성 카탈로그는 설정에서 확인할 수 있으며, 언어별로 필터링 가능합니다

### 국제화

- 인터페이스는 9개 언어로 제공됩니다: fr, en, es, pt, it, nl, de, hi, ar
- AI 프롬프트는 15개 언어를 지원합니다(fr, en, es, de, it, pt, nl, ja, zh, ko, ar, hi, pl, ro, sv)

## 빠른 시작

```bash
# Cloner le dépôt
git clone https://github.com/jls42/EurekAI.git
cd EurekAI

# Installer les dépendances
npm install

# Configurer les clés API
cp .env.example .env
# Éditez .env (toutes optionnelles) :
#   MISTRAL_API_KEY=<your_api_key>           (optionnel — sinon chaque utilisateur saisit sa clé dans l'app)
#   SONAR_TOKEN=...                          (optionnel, CI SonarCloud uniquement)

# Lancer le développement
npm run dev
# → Backend :  http://localhost:3000 (API)
# → Frontend : http://localhost:5173 (serveur Vite avec HMR)
```

> **참고**: Mistral Voxtral TTS는 유일한 TTS 공급자이며 — `MISTRAL_API_KEY` 외에는 추가 키가 필요하지 않습니다.

> **사용자 입력 API 키**: `MISTRAL_API_KEY`는 이제 **선택 사항**입니다. 없더라도 앱은 그대로 시작하며, 각 사용자에게 인터페이스에서 **자신의 Mistral 키**를 입력하라고 안내합니다. 키는 **브라우저에 저장**되며(보안 컨텍스트에서 Web Crypto + IndexedDB를 통해 암호화) 요청과 함께 전송됩니다 — **서버에는 절대 영구 저장되지 않습니다**. 우선순위: 프로필 키 > 전역 브라우저 키 > `MISTRAL_API_KEY`(env). `EUREKAI_REQUIRE_USER_KEY=true`를 설정하면 모든 사용자가 자신의 키를 제공해야 합니다(env 키는 이제 미리 로드할 때만 사용됩니다).

> **로컬 HTTPS(태블릿/LAN)**: `localhost`는 이미 보안 컨텍스트입니다. LAN 접근(태블릿)을 위해 로컬 인증서를 생성하고 HTTPS를 활성화하면 브라우저 암호화를 사용할 수 있고 전송 중 키도 암호화됩니다:
> ```bash
> ./scripts/gen-cert.sh 192.168.1.42   # mkcert si dispo, sinon openssl self-signed
> export HTTPS_KEY=certs/key.pem HTTPS_CERT=certs/cert.pem
> npm run dev                          # Express + Vite en HTTPS
> ```
### 환경 변수

| 변수 | 필수 여부 | 기본값 | 역할 |
|---|---|---|---|
| `MISTRAL_API_KEY` | 선택 사항 | — | Mistral API 키(chat, OCR, STT, TTS Voxtral, agents, 모더레이션). 없으면 사용자가 앱에서 키를 입력합니다(브라우저에 저장, 서버에는 절대 저장되지 않음) |
| `EUREKAI_REQUIRE_USER_KEY` | 선택 사항 | `false` | `true` → AI 요청에 대해 `MISTRAL_API_KEY`로의 폴백을 비활성화합니다(각 사용자가 반드시 자신의 키를 제공해야 함). 노출된 인스턴스에서 유용합니다 |
| `HTTPS_KEY` / `HTTPS_CERT` | 선택 사항 | — | TLS 키/인증서 경로(`scripts/gen-cert.sh` 참조) → Express와 Vite가 HTTPS로 제공됩니다(LAN/태블릿용 secure context) |
| `PORT` | 선택 사항 | `3000` | Express 백엔드의 HTTP 포트 |
| `NODE_ENV` | 선택 사항 | `development` | `production`이면 Express가 `dist/`에서 프런트엔드를 제공합니다(그렇지 않으면 `public/`) |
| `SONAR_TOKEN` | 선택 사항 CI | — | GitHub Actions SonarCloud 워크플로에서만 사용됨 |

| `POST` | `/api/projects/:pid/generate/fill-blank` | 빈칸 채우기 |
| `POST` | `/api/projects/:pid/generate/podcast` | Podcast |

| `POST` | `/api/projects/:pid/generate/quiz-vocal` | 음성 퀴즈 |
| `POST` | `/api/projects/:pid/generate/quiz-review` | 적응형 복습 `{generationId, weakQuestions}` |
| `POST` | `/api/projects/:pid/generate/route` | 라우팅 분석(실행할 생성기 계획) — `{plan, costDelta}`를 반환(라우팅 자체 비용) |
| `POST` | `/api/projects/:pid/generate/auto` | 백엔드 자동 생성(라우팅 + 7개 유형: summary, flashcards, quiz, fill-blank, podcast, quiz-vocal, image). 병렬 실행 — rate-limit이 동시에 7개 이상인 Mistral tier를 전제로 합니다. 그렇지 않으면 여러 429가 `failedSteps`로 올라올 수 있습니다. |

모든 생성 라우트는 `{sourceIds?, lang?, ageGroup?, count?, useConsigne?}`을 허용합니다. `quiz-review`은 추가로 `{generationId, weakQuestions}`를 요구합니다.

## 아키텍처 결정

| 결정 | 근거 |
|---|---|
| **React/Vue 대신 Alpine.js** | 최소한의 용량, Vite가 컴파일한 TypeScript로 가벼운 반응성. 속도가 중요한 해커톤에 딱 맞습니다. |
| **JSON 파일로 지속 저장** | 설정할 데이터베이스가 없습니다 — 시작하면 바로 실행됩니다. |
| **Vite + Handlebars** | 두 세계의 장점: 개발용 빠른 HMR, 코드 구성을 위한 HTML partials, Tailwind JIT. |
| **중앙 집중형 프롬프트** | 모든 AI 프롬프트가 `prompts.ts`에 있어 반복 개선, 테스트, 언어/연령대별 조정이 쉽습니다. |
| **다중 생성 시스템** | 각 생성은 고유 ID를 가진 독립 객체입니다 — 한 코스에서 여러 개의 노트, 퀴즈 등을 만들 수 있습니다. |
| **연령별 맞춤 프롬프트** | 4개 연령 그룹마다 어휘, 복잡도, 톤이 다릅니다 — 같은 내용도 학습자에 따라 다르게 가르칩니다. |
| **Agents 기반 기능** | 이미지 생성과 웹 검색은 임시 Mistral Agents를 사용합니다 — 자동 정리로 깔끔한 생명주기를 유지합니다. |
| **지능형 URL 스크래핑** | 하나의 입력 필드에서 URL과 키워드를 함께 받습니다 — URL은 Readability(정적 페이지)로 스크래핑하고, Lightpanda(JS/SPA 페이지)로 폴백하며, 키워드는 Mistral web_search Agent를 트리거합니다. 각 결과는 독립적인 소스를 생성합니다. |
| **100% Mistral TTS** | Mistral Voxtral TTS(`MISTRAL_API_KEY` 외 추가 키 불필요) — 비용 추적 체인과 언어별 음성 선택에 통합되어 있습니다. |

## 이야기 — 왜 EurekAI인가?

**EurekAI**는 [Mistral AI Worldwide Hackathon](https://luma.com/mistralhack-online) ([공식 사이트](https://worldwide-hackathon.mistral.ai/)) (2026년 3월)에서 탄생했습니다. 주제가 필요했는데, 아이디어는 아주 현실적인 것에서 나왔습니다. 저는 딸과 함께 정기적으로 시험 대비를 하는데, AI를 활용하면 이 과정을 더 재미있고 상호작용적으로 만들 수 있지 않을까 생각했습니다.

목표는 **어떤 입력이든** — 수업 사진, 복사해서 붙여넣은 텍스트, 음성 녹음, 웹 검색 — 을 **복습 노트, 플래시카드, 퀴즈, 팟캐스트, 빈칸 채우기, 일러스트 등**으로 바꾸는 것입니다. 이 모든 것은 Mistral AI의 프랑스 모델로 구동되며, 프랑스어권 학생들에게 자연스럽게 맞는 솔루션이 됩니다.

[초기 프로토타입](https://github.com/jls42/worldwide-hackathon.mistral.ai)은 해커톤 기간 48시간 동안 Mistral 서비스 기반의 개념 증명으로 제작되었으며, 이미 동작은 했지만 제한적이었습니다. 이후 EurekAI는 진짜 프로젝트가 되었습니다: 빈칸 채우기, 연습 문제 내비게이션, 웹 스크래핑, 설정 가능한 부모 통제, 심층 코드 리뷰 등 훨씬 더 많은 기능이 추가되었습니다. 코드 전체는 AI가 생성합니다 — 주로 [Claude Code](https://code.claude.com/)를 사용했고, 일부는 [Codex](https://openai.com/codex/)와 [Gemini CLI](https://geminicli.com/)를 통해 기여되었습니다.

## 심층 탐구 — 기능

### 다중 모달 입력

EurekAI는 프로필에 따라 필터링된 4가지 유형의 소스를 허용합니다(어린이와 청소년에게 기본 활성화) :

- **파일 가져오기** — JPG, PNG 또는 PDF 파일은 Mistral OCR로 처리됩니다 — **OCR 3 (`mistral-ocr-2512`) 기본값**, **OCR 4 (`mistral-ocr-4-0`) 선택 사항**은 설정에서 사용 가능(더 나은 품질, 하지만 비용 2배) — 인쇄 텍스트, 표, 손글씨용입니다. 또는 텍스트 파일(TXT, MD)을 직접 가져올 수 있습니다. 다중 파일 업로드는 **업로드 세션** 시스템을 사용합니다: 파일별 개별 진행률, 다른 파일을 다시 제출하지 않고 실패한 파일만 재시도, 완료되면 세션 종료. OCR은 평균화된 **신뢰도 점수**(`average`, `[0,1]`로 클램프, Mistral이 반환한 `averagePageConfidenceScore`로 계산됨)를 노출하며, UI에는 티어 `high` / `medium` / `low` 배지로 표시됩니다(임계값 약 0.9 / 약 0.7) — 스캔 품질이 좋지 않아도 차단하지 않고 경고만 합니다.
- **자유 텍스트** — 어떤 콘텐츠든 입력하거나 붙여넣으세요. 모더레이션이 활성화되어 있으면 저장 전에 필터링됩니다.
- **음성 입력** — 브라우저에서 오디오를 녹음하세요. `voxtral-mini-latest`가 전사합니다. `language="fr"` 설정이 인식을 최적화합니다.
- **웹 / URL** — 하나 이상의 URL을 붙여넣어 콘텐츠를 직접 스크래핑하거나(Readability + JS 페이지용 Lightpanda), 키워드를 입력해 Mistral 에이전트를 통한 웹 검색을 수행하세요. 단일 필드가 둘 다 허용하며 — URL과 키워드는 자동으로 분리되고, 각 결과는 독립적인 소스를 생성합니다.

### AI 콘텐츠 생성

여덟 가지 학습 자료 유형이 생성됩니다:

| 생성기 | 모델 | 출력 |
|---|---|---|
| **복습 노트** | `mistral-large-latest` | 제목, 요약, 핵심 포인트, 어휘, 인용문, 일화 |
| **플래시카드** | `mistral-large-latest` | 소스 참조가 포함된 Q/A 카드(개수 설정 가능) |
| **객관식 퀴즈** | `mistral-large-latest` | 객관식 문제, 해설, 적응형 복습(개수 설정 가능) |
| **빈칸 채우기** | `mistral-large-latest` | 힌트와 관대한 검증(Levenshtein)이 포함된 완성 문장 |
| **받아쓰기** | `mistral-large-latest` + Voxtral TTS | 핵심 단어를 오디오로 받아쓰기(단어당 1 MP3) → 키보드 입력 → 엄격한 교정(악센트 포함)과 설명된 규칙 |
| **팟캐스트** | `mistral-large-latest` + Voxtral TTS | 2인 음성 스크립트 → MP3 오디오 |
| **일러스트** | 에이전트 `mistral-large-latest` | `image_generation` 도구를 통한 교육용 이미지 |
| **음성 퀴즈** | `mistral-large-latest` + Voxtral TTS + STT | TTS 질문 → STT 응답 → AI 검증 |

### 채팅 기반 AI 튜터

수업 문서에 완전하게 접근할 수 있는 대화형 튜터입니다:

- `mistral-large-latest` 사용
- **도구 호출**: 대화 중에 복습 노트, 플래시카드, 퀴즈, 빈칸 채우기 문제를 생성할 수 있음
- 강의당 최대 50개 메시지의 기록
- 프로필에 대해 활성화되어 있으면 콘텐츠 모더레이션

### 자동 라우터

라우터는 `mistral-small-latest`를 사용해 소스 콘텐츠를 분석하고, 사용 가능한 8가지 생성기 중 가장 관련성 높은 것을 제안합니다. 인터페이스는 실시간 진행률을 표시합니다: 먼저 분석 단계, سپس 개별 생성이 진행되며 필요 시 취소할 수 있습니다.

### 적응형 학습

- **퀴즈 통계**: 문제별 시도 횟수와 정확도 추적
- **퀴즈 복습**: 약한 개념을 겨냥한 5~10개의 새 문제 생성
- **지시문 감지**: 복습 지시문("나는 ...를 알면 내 수업을 안다")을 감지하고 호환되는 텍스트 생성기(노트, 플래시카드, 퀴즈, 빈칸 채우기)에서 우선순위를 높임

### 보안 및 부모 통제

- **4개 연령 그룹**: 어린이(≤10세), 청소년(11-15세), 학생(16-25세), 성인(26세 이상)
- **콘텐츠 모더레이션**: `mistral-moderation-latest`는 10개 카테고리를 제공하며, 어린이/청소년에게는 5개가 기본 차단됩니다(`sexual`, `hate_and_discrimination`, `violence_and_threats`, `selfharm`, `jailbreaking`). 카테고리는 설정에서 프로필별로 사용자 지정할 수 있습니다.
- **부모 PIN**: SHA-256 해시, 15세 미만 프로필에 필요합니다. 프로덕션 배포에서는 솔트가 포함된 느린 해시(Argon2id, bcrypt)를 사용해야 합니다.
- **채팅 제한**: 16세 미만은 AI 채팅이 기본 비활성화되며, 부모가 활성화할 수 있습니다.

### 다중 프로필 시스템

- 이름, 나이, 아바타, 언어 설정이 있는 여러 프로필
- **프로필별 음성** (`Profile.mistralVoices?: { host, guest }`) — 각 아이는 팟캐스트/음성 퀴즈용 음성 쌍을 가질 수 있습니다
- **프로필별 테마** (`Profile.theme: 'dark' | 'light'`) — 프로필 변경 시 자동 전환, 백엔드에 유지됨
- `profileId`를 통해 프로필과 연결된 프로젝트
- 연쇄 삭제: 프로필을 삭제하면 해당 프로젝트도 모두 삭제됨

### API 비용 추적

각 Mistral 호출(chat, OCR, STT, TTS, 모더레이션, 에이전트)은 사용자에게 **투명한** € 추정치를 제공하도록 계측됩니다 — 청구에 놀랄 일이 없습니다.

- **단일 진실의 원천**: `helpers/pricing.ts` — 모델 접두사별 `MODEL_PRICING`(예: `mistral-large` → input 0.5 €/M tokens, output 1.5 €/M tokens), 주기적 재스크래핑을 위한 Mistral 문서 URL을 포함한 `PRICING_SOURCES`
- **지원 단위**: `tokens`, `characters`(TTS), `pages`(OCR), `audio-seconds`(STT) — 변환은 `helpers/cost-calc.ts`가 담당
- **계측 체인**: `helpers/tracked-client.ts`(Mistral 클라이언트 래핑) → `helpers/usage-context.ts`(AsyncLocalStorage) → `helpers/cost-calc.ts` → `helpers/cost-persist.ts` → `helpers/cost-middleware.ts`(HTTP 응답에 주입)
- **UI**: 생성별 비용 배지(`src/partials/cost-badge-gen.html`), 소스별 비용 배지(`cost-badge-src.html`), 대시보드의 누적 총합(`Project.totalCost`)
- **엔드포인트**: `/generate/*` 및 `/sources/*` 응답은 반환된 객체(Generation / Source)에 `estimatedCost`, `usage` 및 `costBreakdown`를 추가합니다. `POST /generate/auto/route`는 라우팅 자체의 비용을 위한 `costDelta: number` 필드를 추가합니다. `GET /projects/:pid`는 `totalCost`(`costLog[]`에서 계산된 합계 포함) + 전체 기록이 풍부해진 프로젝트를 반환합니다.

### 다중 제공자 TTS 및 사용자 지정 음성

- **Mistral Voxtral TTS**: `voxtral-mini-tts-latest`, 100% Mistral 음성 합성, 추가 키가 필요하지 않음
- **사용자 지정 음성**: 부모는 Mistral Voices API를 통해(오디오 샘플 기반) 자신만의 음성을 만들고 호스트/게스트 역할에 할당할 수 있습니다 — 그러면 팟캐스트와 음성 퀴즈가 부모의 목소리로 재생되어 아이에게 더욱 몰입감 있는 경험을 제공합니다
- 두 가지 구성 가능한 음성 역할: **호스트**(주요 내레이터)와 **게스트**(팟캐스트의 두 번째 음성)
- Mistral의 전체 음성 카탈로그는 설정에서 사용할 수 있으며, 언어별로 필터링 가능

### 국제화

- 인터페이스는 9개 언어로 제공됩니다: fr, en, es, pt, it, nl, de, hi, ar
- AI 프롬프트는 15개 언어를 지원합니다(fr, en, es, de, it, pt, nl, ja, zh, ko, ar, hi, pl, ro, sv)
- 프로필별 언어 설정 가능

## 빠른 시작

```bash
# Cloner le dépôt
git clone https://github.com/jls42/EurekAI.git
cd EurekAI

# Installer les dépendances
npm install

# Configurer les clés API
cp .env.example .env
# Éditez .env (toutes optionnelles) :
#   MISTRAL_API_KEY=<your_api_key>           (optionnel — sinon chaque utilisateur saisit sa clé dans l'app)
#   SONAR_TOKEN=...                          (optionnel, CI SonarCloud uniquement)

# Lancer le développement
npm run dev
# → Backend :  http://localhost:3000 (API)
# → Frontend : http://localhost:5173 (serveur Vite avec HMR)
```

> **참고**: Mistral Voxtral TTS는 유일한 TTS 제공자이므로 `MISTRAL_API_KEY` 외에 추가 키가 필요하지 않습니다.

> **사용자 입력 API 키**: `MISTRAL_API_KEY`은 이제 **선택 사항**입니다. 없더라도 앱은 정상적으로 시작되며, 각 사용자에게 인터페이스에서 **자신의 Mistral 키**를 입력하라고 안내합니다. 이 키는 **브라우저에 저장**되며(보안 컨텍스트에서 Web Crypto + IndexedDB를 통해 암호화됨), 요청 시 전송될 뿐입니다 — **서버에는 절대 영구 저장되지 않습니다**. 우선순위: 프로필 키 > 브라우저 전역 키 > `MISTRAL_API_KEY`(env). `EUREKAI_REQUIRE_USER_KEY=true`를 설정하면 모든 사용자가 반드시 자신의 키를 제공해야 합니다(이제 env 키는 사전 로드에만 사용됨).

> **로컬 HTTPS(태블릿/LAN)**: `localhost`은 이미 보안 컨텍스트입니다. LAN(태블릿) 접근을 위해 로컬 인증서를 생성하고 HTTPS를 활성화하면 브라우저 암호화를 사용할 수 있고 키도 전송 중 암호화됩니다:
> ```bash
> ./scripts/gen-cert.sh 192.168.1.42   # mkcert가 있으면 mkcert, 없으면 openssl self-signed
> export HTTPS_KEY=certs/key.pem HTTPS_CERT=certs/cert.pem
> npm run dev                          # HTTPS에서 Express + Vite
> ```

### 환경 변수

| 변수 | 필수 | 기본값 | 역할 |
|---|---|---|---|
| `MISTRAL_API_KEY` | 선택 사항 | — | Mistral API 키(chat, OCR, STT, TTS Voxtral, agents, moderation). 없으면 사용자가 앱에서 자신의 키를 입력함(브라우저에 저장, 서버에는 저장되지 않음) |
| `EUREKAI_REQUIRE_USER_KEY` | 선택 사항 | `false` | `true` → IA 요청에서 `MISTRAL_API_KEY` 폴백을 비활성화함(각 사용자는 반드시 자신의 키를 제공해야 함). 공개 인스턴스에서 유용함 |
| `HTTPS_KEY` / `HTTPS_CERT` | 선택 사항 | — | TLS 키/인증서 경로(`scripts/gen-cert.sh` 참조) → Express와 Vite가 HTTPS로 제공됨(LAN/태블릿 보안 컨텍스트) |
| `PORT` | 선택 사항 | `3000` | Express 백엔드의 HTTP 포트 |
| `NODE_ENV` | 선택 사항 | `development` | `production`이면 Express가 `dist/`에서 프런트엔드를 제공함(그렇지 않으면 `public/`) |
| `SONAR_TOKEN` | 선택 사항 CI | — | GitHub Actions SonarCloud 워크플로에서만 사용됨 |

이 도구들이 없으면 `npm test`은 `pretest`에서 실패하고(lizard 없음), `npm run security`는 실패합니다(opengrep 없음). 그러면 husky 훅이 커밋/푸시를 차단합니다.

## 아키텍처 결정

| 결정 | 근거 |
|---|---|
| **React/Vue 대신 Alpine.js** | 최소한의 footprint, Vite가 컴파일한 TypeScript와 함께 가벼운 반응성 제공. 속도가 중요한 해커톤에 적합함. |
| **JSON 파일 기반 영속성** | 의존성 제로, 즉시 시작 가능. 설정할 데이터베이스가 없음 — 그냥 시작하면 됨. |
| **Vite + Handlebars** | 두 세계의 장점: 개발 시 빠른 HMR, 코드 구성을 위한 HTML partials, Tailwind JIT. |
| **중앙화된 프롬프트** | 모든 AI 프롬프트가 `prompts.ts`에 있음 — 언어/연령대별로 쉽게 반복, 테스트, 조정 가능. |
| **다중 생성 시스템** | 각 생성은 고유 ID를 가진 독립 객체 — 하나의 강의에서 여러 복습 카드, 퀴즈 등을 만들 수 있음. |
| **연령별 맞춤 프롬프트** | 4개 연령대 그룹에 서로 다른 어휘, 복잡도, 톤을 적용 — 같은 콘텐츠도 학습자에 따라 다르게 가르침. |
| **Agent 기반 기능** | 이미지 생성과 웹 검색은 임시 Mistral Agent를 사용 — 자동 정리되는 자체 수명 주기. |
| **지능형 URL 스크래핑** | 하나의 입력 필드가 URL과 키워드가 섞인 입력을 허용함 — URL은 Readability(정적 페이지)로 스크래핑하고, Lightpanda(자바스크립트/SPA 페이지)로 폴백하며, 키워드는 Mistral web_search Agent를 트리거함. 각 결과는 독립적인 소스를 생성함. |
| **100% Mistral TTS** | Mistral Voxtral TTS(`MISTRAL_API_KEY` 외 추가 키 없음) — 비용 체인과 언어별 음성 해상도에 통합된 음성 합성. |

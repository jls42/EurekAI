## 이야기 — 왜 EurekAI인가?

**EurekAI**는 [Mistral AI Worldwide Hackathon](https://luma.com/mistralhack-online) ([공식 사이트](https://worldwide-hackathon.mistral.ai/))(2026년 3월) 동안 탄생했습니다. 주제가 필요했는데, 아주 현실적인 아이디어에서 출발했습니다. 저는 딸과 함께 정기적으로 시험 대비를 하는데, AI를 활용하면 그것을 더 재미있고 인터랙티브하게 만들 수 있겠다고 생각했습니다.

목표는 **어떤 입력이든** — 수업 사진, 복사해 넣은 텍스트, 음성 녹음, 웹 검색 — **복습 자료, 플래시카드, 퀴즈, 팟캐스트, 빈칸 채우기, 일러스트 등**으로 바꾸는 것입니다. 이 모든 것은 Mistral AI의 프랑스산 모델로 구동되며, 프랑스어를 사용하는 학생들에게 자연스럽게 적합한 솔루션이 됩니다.

[초기 프로토타입](https://github.com/jls42/worldwide-hackathon.mistral.ai)은 해커톤 동안 48시간 만에 Mistral 서비스 기반의 개념 증명으로 만들어졌으며, 이미 동작했지만 제한적이었습니다. 그 이후 EurekAI는 진짜 프로젝트가 되었습니다: 빈칸 채우기, 연습문제 탐색, 웹 스크래핑, 구성 가능한 부모 모더레이션, 심층 코드 리뷰 등 훨씬 더 많은 기능이 추가되었습니다. 코드 전체는 AI로 생성되며 — 주로 [Claude Code](https://code.claude.com/), 그리고 [Codex](https://openai.com/codex/)와 [Gemini CLI](https://geminicli.com/)를 통한 일부 기여가 있습니다.

## 심층 살펴보기 — 기능

### 멀티모달 입력

EurekAI는 프로필에 따라 모더레이션되는 4가지 소스 유형을 지원합니다(어린이와 청소년 프로필에서는 기본 활성화됨):

- **파일 가져오기** — JPG, PNG 또는 PDF 파일은 Mistral OCR로 처리됩니다 — **기본 OCR 3 (`mistral-ocr-2512`)**, **선택적 OCR 4 (`mistral-ocr-4-0`)** 는 설정에서 사용할 수 있습니다(품질은 더 좋지만 비용은 2배) — 인쇄 텍스트, 표, 손글씨용; 또는 텍스트 파일(TXT, MD)을 직접 가져올 수 있습니다. 다중 파일 업로드는 **업로드 세션** 시스템을 사용합니다: 파일별 개별 진행률, 실패한 파일만 다시 시도하고 다른 파일은 다시 제출하지 않으며, 완료되면 세션을 닫습니다. OCR은 Mistral이 반환한 `averagePageConfidenceScore`을 바탕으로 계산된 평균 **신뢰도 점수**(`average`, `[0,1]`로 clamp됨)를 노출하며, UI에는 `high` / `medium` / `low` 티어 배지로 표시됩니다(임계값 약 0.9 / 약 0.7) — 스캔 품질이 좋지 않으면 차단하지 않고 경고합니다.
- **자유 텍스트** — 어떤 콘텐츠든 입력하거나 붙여넣으세요. 모더레이션이 활성화되어 있으면 저장 전에 검사됩니다.
- **음성 입력** — 브라우저에서 오디오를 녹음하세요. `voxtral-mini-latest`가 전사합니다. `language="fr"` 매개변수가 인식을 최적화합니다.
- **웹 / URL** — 하나 이상의 URL을 붙여넣어 콘텐츠를 직접 스크래핑하세요(Readability + Lightpanda는 JS 페이지용), 또는 Mistral Agent를 통해 웹 검색할 키워드를 입력하세요. 단일 입력 필드는 둘 다 받아들이며 — URL과 키워드는 자동으로 분리되고, 각 결과는 독립적인 소스를 생성합니다.

### AI 콘텐츠 생성

생성되는 학습 자료는 7가지 유형입니다:

| 생성기 | 모델 | 출력 |
|---|---|---|
| **복습 자료** | `mistral-large-latest` | 제목, 요약, 핵심 포인트, 어휘, 인용문, 일화 |
| **플래시카드** | `mistral-large-latest` | 출처 참조가 포함된 Q/A 카드(개수 설정 가능) |
| **객관식 퀴즈** | `mistral-large-latest` | 객관식 문제, 설명, 적응형 복습(개수 설정 가능) |
| **빈칸 채우기** | `mistral-large-latest` | 힌트와 관대한 검증(Levenshtein)이 포함된 완성형 문장 |
| **팟캐스트** | `mistral-large-latest` + Voxtral TTS | 2인 스크립트 → MP3 오디오 |
| **일러스트** | Agent `mistral-large-latest` | 도구 `image_generation`를 통한 교육용 이미지 |
| **음성 퀴즈** | `mistral-large-latest` + Voxtral TTS + STT | TTS 질문 → STT 응답 → AI 검증 |

### 채팅형 AI 튜터

수업 문서에 완전하게 접근할 수 있는 대화형 튜터입니다:

- `mistral-large-latest`를 사용합니다
- **도구 호출**: 대화 중에 복습 자료, 플래시카드, 퀴즈, 빈칸 채우기 문제를 생성할 수 있습니다
- 과목당 50개 메시지 기록
- 프로필에 대해 활성화되어 있으면 콘텐츠 모더레이션 적용

### 자동 라우터

라우터는 `mistral-small-latest`를 사용해 소스 콘텐츠를 분석하고, 사용 가능한 7가지 생성기 중에서 가장 적절한 것을 제안합니다. 인터페이스는 실시간 진행률을 보여줍니다: 먼저 분석 단계가 진행된 다음, 개별 생성이 이루어지며 필요하면 취소할 수 있습니다.

### 적응형 학습

- **퀴즈 통계**: 각 문제별 시도 횟수와 정확도 추적
- **퀴즈 복습**: 약한 개념을 대상으로 하는 새 문제 5~10개를 생성
- **지시 감지**: 복습 지시문("나는 …를 안다면 수업을 안다고 할 수 있다")을 감지하고, 호환되는 텍스트 생성기(복습 자료, 플래시카드, 퀴즈, 빈칸 채우기)에서 우선 처리

### 보안 및 자녀 보호

- **4개 연령 그룹**: 어린이(≤10세), 청소년(11-15), 학생(16-25), 성인(26+)
- **콘텐츠 모더레이션**: `mistral-moderation-latest`에 10개 카테고리가 있으며, 어린이/청소년은 기본적으로 5개가 차단됩니다(`sexual`, `hate_and_discrimination`, `violence_and_threats`, `selfharm`, `jailbreaking`). 카테고리는 설정에서 프로필별로 사용자 지정할 수 있습니다.
- **부모 PIN**: SHA-256 해시, 15세 미만 프로필에 필요합니다. 프로덕션 배포에서는 소금이 포함된 느린 해시(Argon2id, bcrypt)를 사용하는 것이 좋습니다.
- **채팅 제한**: 16세 미만은 AI 채팅이 기본 비활성화되며, 부모가 활성화할 수 있습니다

### 다중 프로필 시스템

- 이름, 나이, 아바타, 언어 기본 설정이 있는 여러 프로필
- **프로필별 음성**(`Profile.mistralVoices?: { host, guest }`) — 각 아이는 팟캐스트/음성 퀴즈용 음성 쌍을 가질 수 있습니다
- **프로필별 테마**(`Profile.theme: 'dark' | 'light'`) — 프로필 변경 시 자동 전환되며, 백엔드에 유지됩니다
- `profileId`를 통해 프로필에 연결된 프로젝트
- 연쇄 삭제: 프로필을 삭제하면 해당 프로필의 모든 프로젝트도 삭제됩니다

### API 비용 추적

모든 Mistral 호출(chat, OCR, STT, TTS, 모더레이션, agents)은 사용자에게 **투명한** € 추정을 제공하도록 계측되어 있어 — 과금에 놀랄 일이 없습니다.

- **단일 기준 소스**: `helpers/pricing.ts` — 모델 접두사별 `MODEL_PRICING`(예: `mistral-large` → input 0.5 €/M tokens, output 1.5 €/M tokens), 주기적 재스크래핑을 위한 Mistral 문서 URL이 포함된 `PRICING_SOURCES`
- **지원 단위**: `tokens`, `characters`(TTS), `pages`(OCR), `audio-seconds`(STT) — 변환은 `helpers/cost-calc.ts`가 담당
- **계측 체인**: `helpers/tracked-client.ts`(Mistral 클라이언트 wrap) → `helpers/usage-context.ts`(AsyncLocalStorage) → `helpers/cost-calc.ts` → `helpers/cost-persist.ts` → `helpers/cost-middleware.ts`(HTTP 응답에 주입)
- **UI**: 생성별 비용 배지(`src/partials/cost-badge-gen.html`), 소스별(`cost-badge-src.html`), 대시보드의 누적 총합(`Project.totalCost`)
- **엔드포인트**: `/generate/*` 및 `/sources/*` 응답은 반환된 객체(Generation / Source)에 `estimatedCost`, `usage` 및 `costBreakdown`을 추가합니다. `POST /generate/auto/route`는 라우팅 자체의 비용을 위한 `costDelta: number` 필드를 추가합니다. `GET /projects/:pid`는 `totalCost`가 추가된 프로젝트(`costLog[]`에서 계산된 합계)와 전체 히스토리를 반환합니다

### 다중 제공자 TTS 및 맞춤 음성

- **Mistral Voxtral TTS**: `voxtral-mini-tts-latest`, 100% Mistral 음성 합성, 추가 키가 필요하지 않습니다
- **맞춤 음성**: 부모는 Mistral Voices API(오디오 샘플 기반)를 통해 자신만의 음성을 만들고 호스트/게스트 역할에 할당할 수 있습니다 — 그러면 팟캐스트와 음성 퀴즈가 부모의 목소리로 읽혀 아이에게 더욱 몰입감 있는 경험을 제공합니다
- 구성 가능한 두 음성 역할: **호스트**(주요 내레이터)와 **게스트**(팟캐스트의 두 번째 목소리)
- Mistral의 전체 음성 카탈로그는 설정에서 사용할 수 있으며, 언어별로 필터링할 수 있습니다

### 국제화

- 인터페이스는 9개 언어로 제공됩니다: fr, en, es, pt, it, nl, de, hi, ar
- AI 프롬프트는 15개 언어를 지원합니다(fr, en, es, de, it, pt, nl, ja, zh, ko, ar, hi, pl, ro, sv)

## 빠른 시작

```bash
# Cloner le dépôt
git clone https://github.com/jls42/EurekAI.git
cd EurekAI

# Installer les dépendances
npm install

# Configurer les clés API
cp .env.example .env
# Éditez .env (toutes optionnelles) :
#   MISTRAL_API_KEY=<your_api_key>           (optionnel — sinon chaque utilisateur saisit sa clé dans l'app)
#   SONAR_TOKEN=...                          (optionnel, CI SonarCloud uniquement)

# Lancer le développement
npm run dev
# → Backend :  http://localhost:3000 (API)
# → Frontend : http://localhost:5173 (serveur Vite avec HMR)
```

> **참고**: Mistral Voxtral TTS는 유일한 TTS 제공자입니다 — `MISTRAL_API_KEY` 외에 추가 키는 필요하지 않습니다.

> **사용자가 입력한 API 키**: `MISTRAL_API_KEY`는 이제 **선택 사항**입니다. 없더라도 앱은 정상적으로 시작하며, 각 사용자에게 인터페이스에서 **자신의 Mistral 키**를 입력하라고 안내합니다. 키는 **브라우저에 저장**되며(보안 컨텍스트에서 Web Crypto + IndexedDB를 통해 암호화됨) 요청으로 전송됩니다 — **서버에는 절대 영구 저장되지 않습니다**. 우선순위: 프로필 키 > 브라우저 전역 키 > `MISTRAL_API_KEY`(env). `EUREKAI_REQUIRE_USER_KEY=true`를 설정하면 각 사용자가 자신의 키를 반드시 제공해야 합니다(env 키는 이제 프리로드에만 사용됩니다).

> **로컬 HTTPS(태블릿/LAN)**: `localhost`는 이미 보안 컨텍스트입니다. LAN 접근(태블릿용)을 위해 로컬 인증서를 생성하고 HTTPS를 활성화하면 브라우저 암호화를 사용할 수 있고 전송 중 키도 암호화할 수 있습니다:
> ```bash
> ./scripts/gen-cert.sh 192.168.1.42   # mkcert가 있으면 사용, 없으면 openssl self-signed
> export HTTPS_KEY=certs/key.pem HTTPS_CERT=certs/cert.pem
> npm run dev                          # Express + Vite를 HTTPS로 실행
> ```
### 환경 변수

| 변수 | 필수 | 기본값 | 역할 |
|---|---|---|---|
| `MISTRAL_API_KEY` | 선택 사항 | — | Mistral API 키(chat, OCR, STT, Voxtral TTS, 에이전트, 모더레이션). 없으면 사용자가 앱에서 자신의 키를 입력함(브라우저에 저장되며 서버에는 절대 저장되지 않음) |
| `EUREKAI_REQUIRE_USER_KEY` | 선택 사항 | `false` | `true` → AI 요청에 대한 `MISTRAL_API_KEY` 폴백을 비활성화함(각 사용자가 반드시 자신의 키를 제공해야 함). 공개 인스턴스에서 유용함 |
| `HTTPS_KEY` / `HTTPS_CERT` | 선택 사항 | — | TLS 키/인증서 경로(`scripts/gen-cert.sh` 참고) → Express와 Vite가 HTTPS로 제공됨(LAN/태블릿용 보안 컨텍스트) |
| `PORT` | 선택 사항 | `3000` | Express 백엔드의 HTTP 포트 |
| `NODE_ENV` | 선택 사항 | `development` | `production`이면 Express가 `dist/`에서 프런트엔드를 제공함(그렇지 않으면 `public/`) |
| `SONAR_TOKEN` | 선택 사항 CI | — | GitHub Actions SonarCloud 워크플로에서만 사용됨 |

### 테스트, 코드 품질 및 기여

**Git Hooks (Husky)** : `pre-commit`가 `npm test`를 실행하고, `pre-push`가 `npm run security`를 실행한다. 둘 다 실패하면 commit/push를 차단한다.

```bash
# Lizard (Python) pour lint:complexity (CCN > 8 sur l'allowlist)

```

이 도구들이 없으면 `npm test`는 `pretest`에서 실패하고(lizard 없음), `npm run security`은 실패한다(opengrep 없음). 그러면 husky hook이 commit/push를 차단한다.

| `POST` | `/api/projects/:pid/generate/quiz-vocal` | 음성 퀴즈 |
| `POST` | `/api/projects/:pid/generate/quiz-review` | 적응형 복습 `{generationId, weakQuestions}` |
| `POST` | `/api/projects/:pid/generate/remediation-summary` | 퀴즈에서 틀린 질문에 초점을 맞춘 복습 시트 `{generationId, weakQuestions}` — «내 실수로 연습하기» 버튼을 통해 `quiz-review`와 병렬로 호출됨 |
| `POST` | `/api/projects/:pid/generate/route` | 라우팅 분석(실행할 생성기 계획) — `{plan, costDelta}` 반환(라우팅 자체 비용) |
| `POST` | `/api/projects/:pid/generate/auto` | 백엔드 자동 생성(라우팅 + 7개 유형: summary, flashcards, quiz, fill-blank, podcast, quiz-vocal, image). 병렬 실행 — 동시 7개 이상 요청을 허용하는 Mistral 티어가 필요하다. 그렇지 않으면 여러 429가 `failedSteps`에 올라올 수 있다. |

모든 생성 라우트는 `{sourceIds?, lang?, ageGroup?, count?, useConsigne?}`를 허용한다. `quiz-review`과 `remediation-summary`는 추가로 `{generationId, weakQuestions}`를 요구한다.

## 아키텍처 결정

| 결정 | 근거 |
|---|---|
| **React/Vue 대신 Alpine.js** | 최소 풋프린트, Vite가 컴파일한 TypeScript를 통한 가벼운 반응성. 속도가 중요한 해커톤에 딱 맞다. |
| **JSON 파일 영속성** | 의존성 제로, 즉시 시작. 설정할 데이터베이스가 없다 — 바로 시작하면 된다. |
| **Vite + Handlebars** | 두 세계의 장점만 취했다: 개발용 빠른 HMR, 코드 구성을 위한 HTML partials, Tailwind JIT. |
| **프롬프트 중앙 집중화** | 모든 AI 프롬프트를 `prompts.ts`에 모아 두어 언어/연령대별로 쉽게 반복 개선, 테스트, 조정할 수 있다. |
| **다중 생성 시스템** | 각 생성은 고유 ID를 가진 독립 객체다 — 하나의 강의에서 여러 개의 시트, 퀴즈 등을 만들 수 있다. |
| **연령에 맞춘 프롬프트** | 4개 연령 그룹마다 어휘, 복잡도, 톤이 다르다 — 같은 콘텐츠도 학습자에 따라 다르게 가르친다. |
| **Agents 기반 기능** | 이미지 생성과 웹 검색은 임시 Mistral Agents를 사용한다 — 자동 정리로 깔끔한 생명주기를 유지한다. |
| **지능형 URL 스크래핑** | 하나의 필드가 URL과 키워드의 혼합 입력을 허용한다 — URL은 Readability(정적 페이지)로 스크래핑하고 Lightpanda( JS/SPA 페이지 )로 폴백하며, 키워드는 Mistral web_search Agent를 트리거한다. 각 결과는 독립적인 소스를 생성한다. |
| **100% Mistral TTS** | Mistral Voxtral TTS(`MISTRAL_API_KEY` 외 추가 키 없음) — 비용 체인과 언어별 음성 선택에 통합된 음성 합성. |

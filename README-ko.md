## 이야기 — 왜 EurekAI인가?

**EurekAI**는 [Mistral AI Worldwide Hackathon](https://luma.com/mistralhack-online) ([공식 사이트](https://worldwide-hackathon.mistral.ai/))(2026년 3월) 기간에 탄생했습니다. 주제가 필요했고, 아이디어는 아주 현실적인 것에서 나왔습니다. 저는 딸과 함께 정기적으로 시험 대비를 하는데, AI를 활용하면 이를 더 재미있고 인터랙티브하게 만들 수 있지 않을까 생각했습니다.

목표는 **어떤 입력이든** — 수업 사진, 복사해 온 텍스트, 음성 녹음, 웹 검색 — 이를 **복습 자료, 플래시카드, 퀴즈, 팟캐스트, 빈칸 채우기, 일러스트, 그 이상**으로 바꾸는 것입니다. 이 모든 것은 Mistral AI의 프랑스 모델로 구동되며, 프랑스어권 학생들에게 자연스럽게 적합한 솔루션이 됩니다.

[초기 프로토타입](https://github.com/jls42/worldwide-hackathon.mistral.ai)은 해커톤 동안 48시간 만에 Mistral 서비스에 대한 개념 증명으로 설계되었습니다. 이미 동작했지만 기능은 제한적이었습니다. 그 이후 EurekAI는 진짜 프로젝트로 성장했습니다. 빈칸 채우기, 연습 문제 탐색, 웹 스크래핑, 설정 가능한 부모 제어, 심층 코드 리뷰 등 많은 기능이 추가되었습니다. 전체 코드는 AI로 생성되며 — 주로 [Claude Code](https://code.claude.com/), 그리고 일부는 [Codex](https://openai.com/codex/)와 [Gemini CLI](https://geminicli.com/)를 통해 기여되었습니다.

## 심층 살펴보기 — 기능

### 다중 모달 입력

EurekAI는 프로필에 따라 모더레이션된 4가지 소스 유형을 허용합니다(어린이와 청소년은 기본 활성화) :

- **파일 가져오기** — JPG, PNG 또는 PDF 파일은 Mistral OCR로 처리됩니다 — **기본값은 OCR 4 (`mistral-ocr-4-0`)**(최고 품질), **옵션으로 OCR 3 (`mistral-ocr-2512`)**는 설정에서 선택 가능(더 저렴, 비용의 약 절반) — 인쇄 텍스트, 표, 손글씨용; 또는 텍스트 파일(TXT, MD)을 직접 가져올 수 있습니다. 다중 파일 업로드는 **업로드 세션** 시스템을 사용합니다: 파일별 개별 진행률, 다른 파일을 다시 제출하지 않고 실패한 파일만 재시도, 완료 시 세션 닫기. OCR은 평균화된 **신뢰도 점수**(`average`, `[0,1]`로 clamp, Mistral이 반환한 `averagePageConfidenceScore` 기반 계산)를 노출하며, UI에는 `high` / `medium` / `low` 계층 배지로 표시됩니다(임계값 약 0.9 / 약 0.7) — 스캔 품질이 좋지 않을 때 차단하지 않고 경고만 합니다.
- **자유 텍스트** — 어떤 콘텐츠든 입력하거나 붙여넣으세요. 모더레이션이 활성화되어 있으면 저장 전에 검토됩니다.
- **음성 입력** — 브라우저에서 오디오를 녹음하세요. `voxtral-mini-latest`가 전사합니다. `language="fr"` 설정이 인식을 최적화합니다.
- **웹 / URL** — 하나 이상의 URL을 붙여넣어 콘텐츠를 직접 스크래핑하세요(Readability + Lightpanda는 JS 페이지용), 또는 Mistral 에이전트를 통해 웹 검색할 키워드를 입력하세요. 단일 필드가 둘 다 허용합니다 — URL과 키워드는 자동으로 분리되며, 각 결과는 독립된 소스가 됩니다.

### AI 콘텐츠 생성

생성되는 8가지 학습 자료 유형:

| 생성기 | 모델 | 출력 |
|---|---|---|
| **복습 자료** | `mistral-large-latest` | 제목, 요약, 핵심 포인트, 어휘, 인용문, 일화 |
| **플래시카드** | `mistral-large-latest` | 소스 참조가 포함된 Q/A 카드(수량 설정 가능) |
| **객관식 퀴즈** | `mistral-large-latest` | 객관식 문제, 설명, 적응형 복습(수량 설정 가능) |
| **빈칸 채우기** | `mistral-large-latest` | 힌트와 관대한 검증(Levenshtein)이 포함된 완성 문장 |
| **받아쓰기** | `mistral-large-latest` + Voxtral TTS | 오디오로 받아쓰는 키워드(단어당 1 MP3) → 키보드 입력 → 설명된 규칙과 함께 엄격한 교정(악센트) |
| **팟캐스트** | `mistral-large-latest` + Voxtral TTS | 2인용 스크립트 → MP3 오디오 |
| **일러스트** | Agent `mistral-large-latest` | `image_generation` 도구를 통한 교육용 이미지 |
| **음성 퀴즈** | `mistral-large-latest` + Voxtral TTS + STT | TTS 질문 → STT 답변 → AI 검증 |

### 채팅형 AI 튜터

수업 문서에 완전하게 접근할 수 있는 대화형 튜터입니다:

- `mistral-large-latest` 사용
- **도구 호출**: 대화 중에 복습 자료, 플래시카드, 퀴즈 또는 빈칸 채우기 문제를 생성할 수 있음
- 강의당 최대 50개의 메시지 기록
- 프로필에 대해 활성화된 경우 콘텐츠 모더레이션

### 자동 라우터

라우터는 `mistral-small-latest`를 사용해 소스 콘텐츠를 분석하고, 사용 가능한 8가지 항목 중 가장 관련성 높은 생성기를 제안합니다. UI는 실시간 진행률을 표시합니다: 먼저 분석 단계, 그다음 개별 생성이 진행되며 중간에 취소할 수 있습니다.

### 적응형 학습

- **퀴즈 통계**: 문제별 시도 횟수와 정답률 추적
- **퀴즈 복습**: 약한 개념을 겨냥한 새로운 문제 5~10개 생성
- **지시 감지**: 복습 지시문("나는 내 수업을 안다, 왜냐하면 나는...을 안다")을 감지하고 호환되는 텍스트 생성기(복습 자료, 플래시카드, 퀴즈, 빈칸 채우기)에 우선 반영

### 보안 및 부모 통제

- **4개 연령 그룹**: 어린이(≤10세), 청소년(11-15), 학생(16-25), 성인(26+)
- **콘텐츠 모더레이션**: `mistral-moderation-2603`(Mistral Moderation 2) 사용, 사용 가능한 10개 카테고리 중 5개는 어린이/청소년에서 기본 차단(`sexual`, `hate_and_discrimination`, `violence_and_threats`, `selfharm`, `jailbreaking`). 카테고리는 설정에서 프로필별로 사용자 지정 가능. `-latest` 별칭은 의도적으로 사용하지 않습니다(여전히 폐기된 버전을 가리킵니다).
- **부모 PIN**: SHA-256 해시, 15세 미만 프로필에 필요합니다. 프로덕션 배포에서는 느린 해시와 솔트(Argon2id, bcrypt)를 사용하는 것이 좋습니다.
- **채팅 제한**: 16세 미만은 AI 채팅이 기본 비활성화되며, 부모가 활성화 가능

### 멀티 프로필 시스템

- 이름, 나이, 아바타, 언어 설정이 있는 여러 프로필
- **프로필별 음성**(`Profile.mistralVoices?: { host, guest }`) — 각 어린이는 팟캐스트/음성 퀴즈용 음성 쌍을 가질 수 있음
- **프로필별 테마**(`Profile.theme: 'dark' | 'light'`) — 프로필 변경 시 자동 전환, 백엔드에 유지
- `profileId`를 통해 프로필과 연결된 프로젝트
- 연쇄 삭제: 프로필을 삭제하면 해당 프로필의 모든 프로젝트도 삭제됨

### API 비용 추적

모든 Mistral 호출(chat, OCR, STT, TTS, moderation, agents)은 사용자에게 **투명한** € 비용 추정을 제공하도록 계측됩니다. 청구에 놀랄 일이 없습니다.

- **단일 진실 출처**: `helpers/pricing.ts` — 모델 prefix별 `MODEL_PRICING`(예: `mistral-large` → input 0.5 €/M tokens, output 1.5 €/M tokens), 정기적 재스크래핑을 위한 Mistral 문서 URL이 포함된 `PRICING_SOURCES`
- **지원 단위**: `tokens`, `characters`(TTS), `pages`(OCR), `audio-seconds`(STT) — `helpers/cost-calc.ts`가 변환을 관리
- **계측 체인**: `helpers/tracked-client.ts`(Mistral 클라이언트 래핑) → `helpers/usage-context.ts`(AsyncLocalStorage) → `helpers/cost-calc.ts` → `helpers/cost-persist.ts` → `helpers/cost-middleware.ts`(HTTP 응답에 주입)
- **UI**: 생성별 비용 배지(`src/partials/cost-badge-gen.html`), 소스별 배지(`cost-badge-src.html`), 대시보드의 누적 총합(`Project.totalCost`)
- **엔드포인트**: `/generate/*` 및 `/sources/*` 응답은 반환된 객체(Generation / Source)에 `estimatedCost`, `usage`, `costBreakdown`를 덧붙입니다. `POST /generate/route`는 라우팅 자체의 비용을 위한 `costDelta: number` 필드를 추가합니다. `GET /projects/:pid`는 `totalCost`( `costLog[]`에서 계산된 합계 )와 전체 기록이 포함된 강화된 프로젝트를 반환합니다

### TTS(Mistral Voxtral) 및 사용자 지정 음성

- **Mistral Voxtral TTS**: `voxtral-mini-tts-latest`, 100% Mistral 음성 합성, 추가 키가 필요하지 않음
- **사용자 지정 음성**: 부모는 Mistral Voices API(오디오 샘플 기반)를 통해 자신의 음성을 만들고 호스트/게스트 역할에 할당할 수 있습니다 — 그러면 팟캐스트와 음성 퀴즈는 부모의 목소리로 재생되어 아이에게 훨씬 더 몰입감 있는 경험을 제공합니다
- 두 가지 구성 가능한 음성 역할: **호스트**(주요 내레이터)와 **게스트**(팟캐스트의 두 번째 음성)
- Mistral의 전체 음성 카탈로그는 설정에서 확인 가능하며, 언어별로 필터링할 수 있음

### 국제화

- 인터페이스는 9개 언어로 제공됩니다: fr, en, es, pt, it, nl, de, hi, ar
- AI 프롬프트는 15개 언어(fr, en, es, de, it, pt, nl, ja, zh, ko, ar, hi, pl, ro, sv)를 지원합니다
- 언어는 프로필별로 설정 가능

## 빠른 시작

```bash
# Cloner le dépôt
git clone https://github.com/jls42/EurekAI.git
cd EurekAI

# Installer les dépendances
npm install

# Configurer les clés API
cp .env.example .env
# Éditez .env (toutes optionnelles) :
#   MISTRAL_API_KEY=<your_api_key>           (optionnel — sinon chaque utilisateur saisit sa clé dans l'app)
#   SONAR_TOKEN=...                          (optionnel, CI SonarCloud uniquement)

# Lancer le développement
npm run dev
# → Backend :  http://localhost:3000 (API)
# → Frontend : http://localhost:5173 (serveur Vite avec HMR)
```

> **참고**: Mistral Voxtral TTS는 유일한 TTS 제공자이며 — `MISTRAL_API_KEY` 외에 추가 키는 필요하지 않습니다.

> **사용자가 입력한 API 키**: `MISTRAL_API_KEY`는 이제 **선택 사항**입니다. 없더라도 앱은 계속 시작되며, 각 사용자에게 인터페이스에서 **자신의 Mistral 키**를 입력하라고 안내합니다. 키는 **브라우저에 저장**되며(보안 컨텍스트에서 Web Crypto + IndexedDB로 암호화됨) 요청과 함께 전송됩니다 — **서버에 절대 영구 저장되지 않습니다**. 우선순위: 프로필 키 > 브라우저 전역 키 > `MISTRAL_API_KEY`(env). `EUREKAI_REQUIRE_USER_KEY=true`를 설정하면 각 사용자에게 자신의 키 입력을 강제합니다(env 키는 이제 사전 로드에만 사용됨).

> **로컬 HTTPS(태블릿/LAN)**: `localhost`는 이미 보안 컨텍스트입니다. LAN(태블릿) 액세스를 위해 로컬 인증서를 생성하고 HTTPS를 활성화하여 브라우저 암호화를 해제하고 전송 중 키를 암호화하세요:
> ```bash
> ./scripts/gen-cert.sh 192.168.1.42   # mkcert가 있으면 사용, 없으면 openssl self-signed
> export HTTPS_KEY=certs/key.pem HTTPS_CERT=certs/cert.pem
> npm run dev                          # HTTPS에서 Express + Vite
> ```

### 환경 변수

| 변수 | 필요 여부 | 기본값 | 역할 |
|---|---|---|---|
| `MISTRAL_API_KEY` | 선택 사항 | — | Mistral API 키(chat, OCR, STT, TTS Voxtral, agents, moderation). 없으면 사용자가 앱에서 키를 입력함(브라우저에 저장, 서버에는 저장 안 됨) |

## 아키텍처 결정

| 결정 | 근거 |
|---|---|
| **React/Vue 대신 Alpine.js** | 최소한의 footprint, Vite로 컴파일된 TypeScript와 함께하는 가벼운 반응성. 속도가 중요한 해커톤에 완벽합니다. |
| **JSON 파일로 영속화** | 의존성 제로, 즉시 시작. 설정할 데이터베이스가 없습니다 — 시작만 하면 바로 사용 가능합니다. |
| **Vite + Handlebars** | 두 세계의 장점: 개발용 빠른 HMR, 코드 구성을 위한 HTML partials, Tailwind JIT. |
| **중앙화된 프롬프트** | 모든 AI 프롬프트를 `prompts.ts`에 모음 — 언어/연령대별로 반복, 테스트, 조정하기 쉽습니다. |
| **멀티 생성 시스템** | 각 생성은 고유 ID를 가진 독립 객체 — 한 강좌당 여러 복습 카드, 퀴즈 등을 허용합니다. |
| **연령별 맞춤 프롬프트** | 어휘, 복잡도, 톤이 다른 4개 연령 그룹 — 같은 내용도 학습자에 따라 다르게 가르칩니다. |
| **Agents 기반 기능** | 이미지 생성과 웹 검색은 임시 Mistral Agents를 사용 — 자동 정리되는 깔끔한 생명주기. |
| **지능형 URL 스크래핑** | 하나의 입력란이 URL과 키워드를 섞어서 받습니다 — URL은 Readability(정적 페이지)로 스크래핑하고 Lightpanda(JS/SPA 페이지)로 폴백하며, 키워드는 Mistral web_search Agent를 실행합니다. 각 결과는 독립적인 소스를 만듭니다. |
| **TTS 100% Mistral** | Mistral Voxtral TTS(`MISTRAL_API_KEY` 외 추가 키 없음) — 비용 체인과 언어별 음성 해상도에 통합된 음성 합성. |

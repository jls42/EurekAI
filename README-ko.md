## 이야기 — 왜 EurekAI인가?

**EurekAI**는 [Mistral AI 월드와이드 해커톤](https://luma.com/mistralhack-online) ([공식 사이트](https://worldwide-hackathon.mistral.ai/))(2026년 3월)에서 탄생했습니다. 주제가 하나 필요했는데 — 아주 구체적인 것에서 아이디어가 떠올랐습니다. 저는 딸과 함께 정기적으로 시험 준비를 하는데, AI를 활용하면 이 과정을 더 재미있고 상호작용적으로 만들 수 있지 않을까 생각했습니다.

목표는 **어떤 입력이든** — 수업 사진, 복사해 붙인 텍스트, 음성 녹음, 웹 검색 — 받아서 **복습 노트, 플래시카드, 퀴즈, 팟캐스트, 빈칸 채우기, 일러스트, 그 외 여러 가지**로 바꾸는 것입니다. 이 모든 것은 Mistral AI의 프랑스산 모델로 구동되며, 그 결과 프랑스어권 학생들에게 자연스럽게 잘 맞는 솔루션이 됩니다.

[초기 프로토타입](https://github.com/jls42/worldwide-hackathon.mistral.ai)은 해커톤 동안 48시간 만에 Mistral 서비스 기반의 개념 증명으로 만들어졌고 — 이미 작동했지만 제한적이었습니다. 그 이후 EurekAI는 진짜 프로젝트로 발전했습니다: 빈칸 채우기, 연습 문제 내비게이션, 웹 스크래핑, 구성 가능한 보호자 모더레이션, 심층 코드 리뷰, 그리고 더 많은 기능들. 코드 전체는 AI가 생성합니다 — 주로 [Claude Code](https://code.claude.com/), 일부는 [Codex](https://openai.com/codex/)와 [Gemini CLI](https://geminicli.com/)를 통해 기여했습니다.

## 심층 살펴보기 — 기능

### 멀티모달 입력

EurekAI는 프로필에 따라 모더레이션되는 4가지 유형의 소스를 지원합니다(어린이와 청소년은 기본 활성화) :

- **파일 가져오기** — JPG, PNG 또는 PDF 파일은 Mistral OCR로 처리되며 — 기본적으로 **OCR 4 (`mistral-ocr-4-0`)**(가장 좋은 품질), 설정에서 선택 가능한 **OCR 3 (`mistral-ocr-2512`)**(더 저렴하고, 비용의 약 절반) — 인쇄된 텍스트, 표, 손글씨에 적합합니다. 또는 텍스트 파일(TXT, MD)을 직접 가져올 수 있습니다. 다중 파일 업로드는 **업로드 세션** 시스템을 사용합니다: 파일별 개별 진행률, 실패한 파일만 재시도, 다른 파일을 다시 제출하지 않음, 완료되면 세션 닫기. OCR은 Mistral이 반환한 `averagePageConfidenceScore`을 기반으로 계산된 평균 **신뢰도 점수**(`average`, `[0,1]` 범위로 고정됨)를 표시하며, UI에서는 `high` / `medium` / `low` 등급 배지(임계값 약 0.9 / 약 0.7)로 보여 줍니다 — 스캔 품질이 나쁠 때는 차단하지 않고 경고만 표시합니다.
- **자유 텍스트** — 어떤 콘텐츠든 입력하거나 붙여넣을 수 있습니다. 모더레이션이 활성화되어 있으면 저장 전에 모더레이션됩니다.
- **음성 입력** — 브라우저에서 오디오를 녹음합니다. `voxtral-mini-latest`가 전사합니다. `language="fr"` 설정이 인식을 최적화합니다.
- **웹 / URL** — 하나 이상의 URL을 붙여넣어 직접 콘텐츠를 스크래핑할 수 있습니다(Readability + Lightpanda, JS 페이지용). 또는 Agent Mistral을 통해 웹 검색할 키워드를 입력할 수도 있습니다. 하나의 입력란이 둘 다 받으며 — URL과 키워드는 자동으로 분리되고, 각 결과는 독립된 소스로 생성됩니다.

### AI 콘텐츠 생성

생성되는 학습 자료는 8가지 유형입니다:

| 생성기 | 모델 | 출력 |
|---|---|---|
| **복습 노트** | `mistral-large-latest` | 제목, 요약, 핵심 포인트, 어휘, 인용문, 일화 |
| **플래시카드** | `mistral-large-latest` | 출처 참조가 포함된 Q/A 카드(개수 설정 가능) |
| **객관식 퀴즈** | `mistral-large-latest` | 객관식 문제, 설명, 적응형 복습(개수 설정 가능) |
| **빈칸 채우기** | `mistral-large-latest` | 힌트와 관대한 검증(Levenshtein)이 있는 완성형 문장 |
| **받아쓰기** | `mistral-large-latest` + Voxtral TTS | 오디오로 읽어 주는 핵심 단어(단어당 1 MP3) → 키보드 입력 → 엄격한(악센트 포함) 채점 및 설명된 규칙 |
| **팟캐스트** | `mistral-large-latest` + Voxtral TTS | 2인 스크립트 → MP3 오디오 |
| **일러스트** | Agent `mistral-large-latest` | 도구 `image_generation`를 통한 교육용 이미지 |
| **음성 퀴즈** | `mistral-large-latest` + Voxtral TTS + STT | TTS 질문 → STT 답변 → AI 검증 |

### 채팅형 AI 튜터

수업 문서 전체에 접근할 수 있는 대화형 튜터:

- `mistral-large-latest` 사용
- **도구 호출**: 대화 중에 노트, 플래시카드, 퀴즈, 빈칸 채우기를 생성할 수 있음
- 과정당 50개 메시지 기록
- 프로필에 대해 활성화되어 있으면 콘텐츠 모더레이션 적용

### 자동 라우터

라우터는 `mistral-small-latest`를 사용해 소스 콘텐츠를 분석하고, 사용 가능한 8가지 생성기 중 가장 적절한 것들을 제안합니다. 인터페이스는 진행 상황을 실시간으로 보여 줍니다: 먼저 분석 단계가 나오고, 그다음 개별 생성이 진행되며 필요하면 취소할 수 있습니다.

### 적응형 학습

- **퀴즈 통계**: 문제별 시도 횟수와 정답률 추적
- **퀴즈 복습**: 약한 개념을 겨냥한 새 문제 5~10개 생성
- **지시문 감지**: 복습 지시문("내가 ...를 알면 수업을 안다고 말할 수 있다")을 감지해 호환되는 텍스트 생성기(노트, 플래시카드, 퀴즈, 빈칸 채우기)에서 우선순위를 높임

### 보안 및 보호자 제어

- **4개 연령 그룹**: 어린이(≤10세), 청소년(11-15세), 학생(16-25세), 성인(26세+)
- **콘텐츠 모더레이션**: 사용 가능한 10개 카테고리와 함께 `mistral-moderation-2603`(Mistral Moderation 2)를 사용하며, 어린이/청소년은 기본적으로 5개가 차단됩니다(`sexual`, `hate_and_discrimination`, `violence_and_threats`, `selfharm`, `jailbreaking`). 카테고리는 설정에서 프로필별로 사용자 지정할 수 있습니다. `-latest` 별칭은 의도적으로 사용하지 않습니다(여전히 deprecated 버전을 가리킵니다).
- **보호자 PIN**: SHA-256 해시, 15세 미만 프로필에 필요합니다. 프로덕션 배포에서는 솔트가 있는 느린 해시(Argon2id, bcrypt)를 고려하세요.
- **채팅 제한**: 16세 미만은 기본적으로 AI 채팅이 비활성화되어 있으며, 부모가 활성화할 수 있습니다

### 다중 프로필 시스템

- 이름, 나이, 아바타, 언어 선호도를 가진 여러 프로필
- **프로필별 음성** (`Profile.mistralVoices?: { host?, guest? }` — 각 역할은 선택 사항) — 각 아이는 팟캐스트/음성 퀴즈용 음성 한 쌍을 가질 수 있음
- **프로필별 테마** (`Profile.theme: 'dark' | 'light'`) — 프로필 변경 시 자동 전환, 백엔드에 저장됨
- `profileId`를 통해 프로필과 연결된 프로젝트
- 연쇄 삭제: 프로필을 삭제하면 해당 프로필의 모든 프로젝트도 삭제됨

### API 비용 추적

모든 Mistral 호출(채팅, OCR, STT, TTS, 모더레이션, 에이전트)은 사용자에게 **투명한** € 예상 비용을 제공하도록 계측됩니다 — 요금 청구에 대한 놀라움이 없습니다.

- **기준 소스** : `helpers/pricing.ts` — 모델 접두사별 `MODEL_PRICING`(예: `mistral-large` → input 0.5 €/M tokens, output 1.5 €/M tokens), 주기적 재스크래핑을 위한 Mistral 문서 URL이 포함된 `PRICING_SOURCES`
- **지원 단위** : `tokens`, `characters`(TTS), `pages`(OCR), `audio-seconds`(STT) — `helpers/cost-calc.ts`가 변환을 관리
- **계측 체인** : `helpers/tracked-client.ts`(Mistral 클라이언트 래핑) → `helpers/usage-context.ts`(AsyncLocalStorage) → `helpers/cost-calc.ts` → `helpers/cost-persist.ts` → `helpers/cost-middleware.ts`(HTTP 응답에 주입)
- **UI** : 생성별 비용 배지(`src/partials/cost-badge-gen.html`), 소스별 배지(`cost-badge-src.html`), 대시보드의 누적 총액(`Project.totalCost`)
- **엔드포인트** : `/generate/*` 및 `/sources/*` 응답이 반환 객체(Generation / Source)에 `estimatedCost`, `usage`, `costBreakdown`를 붙입니다. `POST /generate/route`는 라우팅만의 비용을 위한 `costDelta: number` 필드를 추가합니다. `GET /projects/:pid`는 `totalCost`( `costLog[]`에서 계산된 합계) + 전체 기록이 포함된 프로젝트를 반환합니다

### TTS (Mistral Voxtral) & 사용자 지정 음성

- **Mistral Voxtral TTS** : `voxtral-mini-tts-latest`, 100% Mistral 음성 합성, 추가 키 불필요
- **사용자 지정 음성** : 부모는 Mistral Voices API(오디오 샘플 기반)를 통해 자신의 음성을 만들고 호스트/게스트 역할에 할당할 수 있습니다 — 그러면 팟캐스트와 음성 퀴즈가 부모의 목소리로 재생되어 아이에게 더욱 몰입감 있는 경험이 됩니다
- 설정 가능한 두 가지 음성 역할: **호스트**(주 내레이터)와 **게스트**(팟캐스트의 두 번째 목소리)
- Mistral 음성 전체 카탈로그는 설정에서 사용할 수 있으며, 언어별로 필터링 가능합니다

### 국제화

- 인터페이스는 9개 언어로 제공됩니다: fr, en, es, pt, it, nl, de, hi, ar
- AI 프롬프트는 15개 언어(fr, en, es, de, it, pt, nl, ja, zh, ko, ar, hi, pl, ro, sv)를 지원합니다
- 프로필별로 언어 설정 가능

```bash
# Cloner le dépôt
git clone https://github.com/jls42/EurekAI.git

npm install

# Configurer les clés API
cp .env.example .env

npm run dev
# → Backend :  http://localhost:3000 (API)
# → Frontend : http://localhost:5173 (serveur Vite avec HMR)
```

> **참고** : Mistral Voxtral TTS는 유일한 TTS 제공자이므로 — `MISTRAL_API_KEY` 외에 추가 키는 필요하지 않습니다.

> **사용자 입력 API 키** : `MISTRAL_API_KEY`는 이제 **선택 사항**입니다. 키가 없어도 앱은 계속 시작되며, 각 사용자에게 인터페이스에서 **자신의 Mistral 키**를 입력하라고 안내합니다. 키는 **브라우저에 저장**되며(보안 컨텍스트에서 Web Crypto + IndexedDB로 암호화됨) 요청 시 전송됩니다 — **서버에 절대 영구 저장되지 않습니다**. 우선순위: 프로필 키 > 브라우저 전역 키 > `MISTRAL_API_KEY`(env). `EUREKAI_REQUIRE_USER_KEY=true`를 설정하면 각 사용자가 반드시 자신의 키를 제공해야 합니다(env 키는 이제 프리로드에만 사용됨).

> **로컬 HTTPS(태블릿/LAN)** : `localhost`는 이미 보안 컨텍스트입니다. LAN 접근(태블릿)을 위해 로컬 인증서를 생성하고 HTTPS를 활성화하여 브라우저 암호화를 해제하고 전송 중 키를 암호화하세요:
> ```bash
> ./scripts/gen-cert.sh 192.168.1.42   # mkcert가 있으면 사용, 없으면 openssl self-signed
> export HTTPS_KEY=certs/key.pem HTTPS_CERT=certs/cert.pem
> npm run dev                          # Express + Vite를 HTTPS로 실행
> ```

## 아키텍처 결정

| 결정 | 근거 |
|---|---|
| **React/Vue보다 Alpine.js** | 최소한의 무게, Vite로 컴파일되는 TypeScript와 함께 가벼운 반응성. 속도가 중요한 해커톤에 딱 맞음. |
| **JSON 파일 기반 영속성** | 의존성 제로, 즉시 시작. 설정할 데이터베이스가 없음 — 그냥 시작하면 바로 동작함. |
| **Vite + Handlebars** | 두 세계의 장점: 개발용 빠른 HMR, 코드 조직을 위한 HTML partials, Tailwind JIT. |
| **중앙집중식 프롬프트** | 모든 AI 프롬프트가 `prompts.ts`에 있음 — 언어/연령대별로 쉽게 반복 개선, 테스트, 조정 가능. |
| **다중 생성 시스템** | 각 생성은 자체 ID를 가진 독립 객체 — 한 강좌에 여러 노트, 퀴즈 등을 허용함. |
| **연령별 맞춤 프롬프트** | 어휘, 복잡도, 톤이 다른 4개 연령 그룹 — 같은 콘텐츠도 학습자에 따라 다르게 가르침. |
| **Agents 기반 기능** | 이미지 생성과 웹 검색은 임시 Mistral Agents를 사용 — 자동 정리되는 깔끔한 수명 주기. |
| **지능형 URL 스크래핑** | 하나의 필드에 URL과 키워드를 섞어 입력할 수 있음 — URL은 Readability로 스크랩하고(정적 페이지) JS/SPA 페이지는 Lightpanda로 폴백하며, 키워드는 Mistral web_search Agent를 트리거함. 각 결과는 독립적인 소스를 생성함. |
| **100% Mistral TTS** | Mistral Voxtral TTS(`MISTRAL_API_KEY` 외 추가 키 없음) — 비용 체인과 언어별 음성 선택에 통합된 음성 합성. |

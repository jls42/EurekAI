## 탄생 이야기 — 왜 EurekAI인가요?

**EurekAI**는 [Mistral AI 전 세계 해커톤](https://luma.com/mistralhack-online)([공식 사이트](https://worldwide-hackathon.mistral.ai/)) 기간인 2026년 3월에 탄생했습니다. 주제가 필요했는데, 아이디어는 아주 구체적인 일상에서 나왔습니다. 저는 딸과 함께 정기적으로 시험을 준비하는데, 인공지능을 활용하면 이 과정을 더 재미있고 상호작용이 풍부하게 만들 수 있겠다고 생각했습니다.

목표는 **어떤 입력이든** — 수업 자료 사진, 복사해 붙여 넣은 텍스트, 음성 녹음, 웹 검색 — **복습 노트, 암기 카드, 퀴즈, 팟캐스트, 빈칸 채우기, 삽화 등**으로 바꾸는 것입니다. 이 모든 기능은 프랑스 기업인 Mistral AI의 모델로 구동되므로, EurekAI는 프랑스어권 학생들에게 자연스럽게 잘 맞는 솔루션입니다.

[초기 프로토타입](https://github.com/jls42/worldwide-hackathon.mistral.ai)은 해커톤 기간 중 48시간 만에 Mistral 서비스를 기반으로 만든 개념 증명이었습니다. 이미 작동했지만 기능은 제한적이었습니다. 이후 EurekAI는 빈칸 채우기, 연습 문제 간 이동, 웹 스크래핑, 설정 가능한 보호자 콘텐츠 검토, 심층 코드 검토 등 다양한 기능을 갖춘 본격적인 프로젝트로 성장했습니다. 코드 전체는 인공지능으로 생성되었으며, 주로 [Claude Code](https://code.claude.com/)를 사용했고 [Codex](https://openai.com/codex/)와 [Gemini CLI](https://geminicli.com/)도 일부 기여했습니다.

## 자세히 살펴보기 — 기능

### 멀티모달 입력

EurekAI는 4가지 유형의 자료를 지원하며 프로필에 따라 콘텐츠를 검토합니다(어린이 및 청소년 프로필에서는 콘텐츠 검토가 기본으로 활성화됨).

- **파일 가져오기** — JPG, PNG 또는 PDF 파일을 Mistral OCR로 처리합니다. 기본 모델은 **OCR 4.1**(`mistral-ocr-4-1`)이며, 설정에서 **OCR 3**(`mistral-ocr-2512`)을 선택할 수도 있습니다(더 저렴하며 비용은 약 ½, 손글씨 인식에 더 강함). 인쇄된 텍스트, 표, 손글씨를 처리하거나 텍스트 파일(TXT, MD)을 직접 가져옵니다. 여러 파일을 업로드할 때는 **업로드 세션**을 사용합니다. 파일별 개별 진행률을 표시하고, 다른 파일을 다시 제출하지 않고 실패한 파일만 재시도하며, 완료된 세션을 닫을 수 있습니다. OCR은 **평균 신뢰도 점수**를 제공합니다(`average`, `[0,1]` 범위로 제한되며 Mistral이 반환한 `averagePageConfidenceScore`에서 계산). 인터페이스에서는 `high` / `medium` / `low` 등급 배지로 표시됩니다(임계값 약 0.9 / 약 0.7). 스캔 품질이 낮으면 처리를 차단하지 않고 경고합니다. OCR 처리를 위해 Mistral로 전송한 문서 사본은 실패 여부와 관계없이 처리가 끝나는 즉시 삭제됩니다.
- **자유 텍스트** — 어떤 콘텐츠든 입력하거나 붙여 넣습니다. 콘텐츠 검토가 활성화되어 있으면 저장 전에 검토합니다.
- **음성 입력** — 브라우저에서 음성을 녹음합니다. 기본적으로 **Voxtral Mini Transcribe 2**(`voxtral-mini-2602`)가 텍스트로 변환하며, 설정에서 **Voxtral Mini Transcribe 3** 및 **Voxtral Small Transcribe 3**(Mistral 미리 보기 버전)을 선택할 수도 있습니다. 인식 성능을 높이기 위해 인터페이스 언어가 모델에 전달됩니다(`language`).
- **웹 / URL** — 하나 이상의 URL을 붙여 넣어 콘텐츠를 직접 스크래핑하거나(JavaScript 페이지에는 Readability + Lightpanda 사용), 키워드를 입력해 Mistral 에이전트로 웹을 검색합니다. 하나의 입력란에서 둘 다 지원하며, URL과 키워드를 자동으로 분리하고 각 결과를 독립된 자료로 생성합니다.

### 인공지능 콘텐츠 생성

8가지 유형의 학습 자료를 생성합니다.

| 생성기 | 모델 | 출력 |
|---|---|---|
| **복습 노트** | `mistral-large-latest` | 제목, 요약, 핵심 내용, 어휘, 인용문, 흥미로운 이야기 |
| **암기 카드** | `mistral-large-latest` | 출처 참조가 포함된 질문/답변 카드(개수 설정 가능) |
| **객관식 퀴즈** | `mistral-large-latest` | 정답이 하나인 4지선다 문항, 설명, 적응형 복습(문항 수 설정 가능) |
| **빈칸 채우기** | `mistral-large-latest` | 힌트가 있는 문장 완성, 사소한 차이를 허용하는 정답 판정(Levenshtein) |
| **받아쓰기** | `mistral-large-latest` + Voxtral TTS | 핵심 단어를 음성으로 제시(단어당 MP3 1개) → 키보드 입력 → 규칙 설명이 포함된 엄격한 채점(발음 구별 부호를 빠뜨려도 오답 처리) |
| **팟캐스트** | `mistral-large-latest` + Voxtral TTS | 두 목소리용 대본 → MP3 음성 |
| **삽화** | 에이전트 `mistral-large-latest` | `image_generation` 도구를 통한 교육용 이미지 |
| **음성 퀴즈** | `mistral-large-latest` + Voxtral TTS + STT | TTS 질문 → STT 답변 → 인공지능 확인 |

### 채팅형 인공지능 학습 도우미

수업 문서에 완전히 접근할 수 있는 대화형 학습 도우미입니다.

- `mistral-large-latest` 사용
- **도구 호출**: 대화 중 복습 노트, 암기 카드, 퀴즈, 빈칸 채우기 생성 가능
- 수업별 메시지 50개 기록
- 프로필의 콘텐츠 검토가 활성화되어 있으면 메시지를 확인하고, 문제가 감지된 자료, 확인에 실패한 자료, 아직 확인하지 않은 자료를 대화 맥락과 도구에서 제외합니다(확인에 실패했거나 아직 확인하지 않은 자료는 먼저 최대 5초 동안 재검사).

### 자동 라우터

라우터는 `mistral-small-latest`을 사용하여 자료의 내용을 분석하고, 사용 가능한 8가지 생성기 중 가장 적합한 생성기를 제안합니다. 인터페이스는 진행 상황을 실시간으로 표시합니다. 먼저 분석 단계를 보여 주고, 이어서 취소 가능한 개별 생성 작업을 표시합니다.

자동 생성은 서버에서 실행되므로 페이지를 새로고침하거나 다른 수업을 열거나 프로필을 바꿔도 계속됩니다. 수업당 자동 생성 작업은 한 번에 하나만 실행됩니다(두 번째 탭은 진행 중인 작업에 연결됨). 서버는 Mistral 키당 최대 3개의 생성 작업을 동시에 실행합니다. 각 생성 작업이 완료되면 메시지가 표시되고, 마지막에는 최종 결과가 한 번만 표시됩니다. 다른 수업을 보고 있을 때 완료되면 메시지에 해당 수업 이름이 표시됩니다. 개별적으로 취소한 생성 작업은 최종 결과에서 실패로 집계되지 않습니다. « 모두 취소 »를 누르면 해당 수업의 전체 묶음을 중지하고 메시지를 하나만 표시합니다. 자동 생성 도중 서버가 재시작되면 작업이 중단되었다고 표시되며, « 다시 시작 » 버튼으로 분석을 다시 하지 않고 완료되지 않은 생성 작업만 재개할 수 있습니다.

탭에서 시작한 장시간 생성 작업은 최대 3개까지 동시에 실행됩니다(개별적으로 시작한 생성 작업, 복습 카드). 이후 작업은 차례를 기다리며, 진행 중인 생성 작업이 끝날 때까지 기다리지 않고 수업을 열 수 있습니다.

### 적응형 학습

- **퀴즈 통계**: 문항별 시도 횟수와 정답률 추적
- **퀴즈 복습**: 원래 퀴즈의 자료를 바탕으로 취약한 개념에 초점을 맞춘 새 문항 5-10개 생성(콘텐츠 검토도 같은 자료에 적용)
- **학습 지침 감지**: 복습 지침("다음을 할 수 있으면 수업 내용을 이해한 것입니다...")을 감지하여 지원되는 텍스트 생성기(복습 노트, 암기 카드, 퀴즈, 빈칸 채우기)에서 우선 반영합니다. 콘텐츠 검토가 활성화되어 있으면 자료 확인이 끝날 때까지 기다린 뒤 안전하다고 판단된 자료만 읽습니다. 지침에는 원본 자료 목록이 유지됩니다. 그중 하나라도 문제가 감지되면 지침을 표시하거나 적용하지 않고, 하나라도 삭제되면 지침도 삭제합니다. 이 작업의 비용도 집계됩니다
### 보안 및 자녀 보호

- **4개 연령 그룹**: 어린이(≤10세), 청소년(11-15), 학생(16-25), 성인(26+)
- **콘텐츠 검토**: `mistral-moderation-2603`(Mistral Moderation 2)은 11개 범주를 제공하며, 새 어린이/청소년 프로필에서는 기본적으로 6개 범주가 차단됩니다(`sexual`, `hate_and_discrimination`, `violence_and_threats`, `criminal`, `selfharm`, `jailbreaking`; `criminal`은 역사 수업을 포함한 50개 수업에서 오탐이 전혀 없음을 확인한 후 추가됨). 설정에서 프로필별로 범주를 맞춤 설정할 수 있습니다. Moderation 2에서는 기존의 « 위험한 콘텐츠 » 범주를 `dangerous` + `criminal`으로 분리했습니다(기존 프로필은 자동으로 이전되며, 차단 범주는 이미 가져온 자료에도 적용됩니다). 기본 보안 정책: 모델 응답으로 차단 범주를 확인할 수 없으면 콘텐츠가 거부됩니다(« 콘텐츠 검토를 사용할 수 없음 »). 콘텐츠 검토가 활성화되어 있으면 생성과 채팅 모두 신고된 자료, 검증에 실패한 자료, 검증 중인 자료를 제외합니다. 한 번도 검증되지 않은 자료(콘텐츠 검토가 비활성화된 상태에서 가져온 자료 또는 프로필에 연결된 기존 프로젝트의 자료)는 사용 전에 검증합니다. 재시작으로 중단된 콘텐츠 검토는 서버 키를 사용할 수 있으면 시작 시 재개됩니다. 그렇지 않으면 오류가 발생한 콘텐츠 검토와 마찬가지로 프로젝트를 열거나 다음 생성을 실행할 때 재개됩니다. « 다시 검증 » 버튼으로 원할 때 검증을 다시 실행할 수 있습니다. 콘텐츠 검토가 활성화되어 있으면 자료가 안전하다고 판단될 때까지 어린이에게 해당 콘텐츠가 숨겨집니다(미리 보기, 텍스트, 원본 문서). 부모는 자신의 PIN으로 한 번만 열람할 수 있습니다. 음성 퀴즈의 구두 답변은 정답 확인 전에 콘텐츠 검토를 거칩니다. 날짜가 포함된 식별자는 `helpers/moderation-model.ts`에 고정되어 있습니다. 사용 중단된 별칭 `-latest`은 더 이상 API에 표시되지 않습니다.
- **부모 PIN**: SHA-256 해시를 사용하며, 15세 미만 프로필에는 필수입니다. IP 주소별로 15분당 잘못된 코드 입력은 최대 10회까지 허용됩니다(429 `rate_limited`). 운영 환경에 배포할 때는 솔트를 사용하는 느린 해시(Argon2id, bcrypt)를 적용하세요.
- **서버 데이터**: `/output`은 프로젝트의 미디어(오디오, 이미지, 가져온 파일)만 공개합니다. `profiles.json`, `config.json`, `projects.json` 및 `project.json`은 절대 제공되지 않습니다.
- **채팅 제한**: 16세 미만은 기본적으로 AI 채팅이 비활성화되며, 부모가 활성화할 수 있습니다.

### 다중 프로필 시스템

- 이름, 나이, 아바타, 언어 환경 설정을 갖춘 여러 프로필
- **프로필별 음성**(`Profile.mistralVoices?: { host?, guest? }` — 각 역할은 선택 사항) — 어린이마다 팟캐스트/음성 퀴즈용 음성 쌍을 지정할 수 있습니다.
- **프로필별 테마**(`Profile.theme: 'dark' | 'light'`) — 프로필 변경 시 자동으로 전환되며 백엔드에 저장됩니다.
- 프로젝트는 `profileId`을 통해 프로필에 연결됩니다. 프로필이 없는 기존 프로젝트는 처음으로 여는 프로필에 연결된 후 해당 프로필의 기준에 따라 콘텐츠 검토를 거칩니다.
- 연쇄 삭제: 프로필을 삭제하면 해당 프로필의 모든 프로젝트가 삭제됩니다.

### API 비용 추적

지시 사항 감지와 음성 퀴즈의 구두 답변을 포함하여, 요금이 부과되는 모든 Mistral 호출(채팅, OCR, STT, TTS, 에이전트)을 계측해 사용자에게 **투명한** € 예상 비용을 제공합니다. 무료인 콘텐츠 검토는 계산에 포함하지 않습니다. 에이전트의 도구 사용료도 포함됩니다. 웹 검색당 0,03 $, 이미지 생성당 0,10 $(Mistral 요금)에 더해, 도구가 생성한 토큰은 에이전트 모델의 입력 요금으로 예상 비용에 반영됩니다.

- **기준 데이터**: `helpers/pricing.ts` — 모델 접두사별 `MODEL_PRICING`(예: `mistral-large` → 입력 0.5 €/M 토큰, 출력 1.5 €/M 토큰), 주기적인 재수집을 위한 Mistral 문서 URL이 포함된 `PRICING_SOURCES`
- **지원 단위**: `tokens`, `characters`(TTS), `pages`(OCR), `audio-seconds`(STT) — `helpers/cost-calc.ts`에 따라 변환
- **계측 흐름**: `helpers/tracked-client.ts`(Mistral 클라이언트를 감쌈) → `helpers/usage-context.ts`(AsyncLocalStorage) → `helpers/cost-calc.ts` → `helpers/cost-persist.ts` → `helpers/cost-middleware.ts`(HTTP 응답에 삽입)
- **사용자 인터페이스**: 생성별 비용 배지(`src/partials/cost-badge-gen.html`), 자료별 비용 배지(`cost-badge-src.html`), 대시보드의 누적 합계(`Project.totalCost`)
- **엔드포인트**: `/generate/*` 및 `/sources/*` 응답은 반환 객체(`Generation` / `Source`)에 `estimatedCost`, `usage`, `costBreakdown`을 추가합니다. `POST /generate/route`는 라우팅 자체의 비용을 위한 `costDelta: number` 필드를 추가합니다. `POST /detect-consigne`(`{consigne, costDelta}`)와 구두 답변 검증도 각각 `costDelta`을 반환합니다. `GET /projects/:pid`은 `totalCost`(`costLog[]`에서 계산한 합계)이 추가된 프로젝트와 전체 기록을 반환합니다.

### TTS(Mistral Voxtral) 및 맞춤 음성

- **Mistral Voxtral TTS**: 기본값은 **Voxtral TTS**(`voxtral-mini-tts-2603`)이며, 설정에서 **Voxtral TTS 3**(`voxtral-mini-tts-3-0`, Mistral 사전 공개 버전, 더 많은 언어의 기본 음성 제공)를 선택할 수 있습니다. 음성 합성은 100% Mistral을 사용하며 추가 키가 필요하지 않습니다. 선택한 모델이 지원하는 음성만 표시됩니다. Voxtral TTS는 Voxtral 3에서 추가된 음성을 지원하지 않습니다.
- **맞춤 음성**: 부모는 Mistral Voices API를 통해 오디오 샘플로 자신의 음성을 만들고 진행자/게스트 역할에 할당할 수 있습니다. 그러면 팟캐스트와 음성 퀴즈를 부모의 목소리로 읽어 주어 어린이의 몰입감을 높입니다.
- 설정 가능한 두 가지 음성 역할: **진행자**(주 내레이터)와 **게스트**(팟캐스트의 두 번째 음성)
- 설정에서 전체 Mistral 음성 목록을 확인하고 언어별로 필터링할 수 있습니다.
- 읽기 재생(학습 자료, 팟캐스트, 받아쓰기 단어)은 해당 화면을 벗어나면 일시 정지되고, 다시 돌아오면 멈춘 위치에서 재개됩니다.
- 플래시카드 읽어 주기 오디오는 처음 들을 때 생성되어 해당 생성 결과에 보관됩니다. 다시 돌아올 때마다 재생성되거나 요금이 다시 청구되지 않습니다.
- 자료 출처 표시(`[Source N]`)는 소리 내어 읽지 않습니다.

| `voxtral-mini-transcribe-3-0` / `voxtral-small-transcribe-3-0` (Transcribe 3, 선택 사항, 사전 공개 버전) | 음성 인식(STT) | 설정에서 선택 가능($0.0035 / min 및 $0.004 / min) |
| `voxtral-mini-tts-2603` (Voxtral TTS, 기본값) | 음성 합성(TTS) | 팟캐스트, 음성 퀴즈, 받아쓰기, 읽어 주기($16 / M 문자) |
| `voxtral-mini-tts-3-0` (Voxtral TTS 3, 선택 사항, 사전 공개 버전) | 음성 합성(TTS) | 설정에서 선택 가능, 더 많은 언어의 기본 음성 제공($13 / M 문자) |
| `mistral-moderation-2603` | 콘텐츠 검토 | 어린이/청소년용으로 6개 범주 차단(`jailbreaking` 포함) |
| `mistral-small-latest` | 자동 라우터 | 라우팅 결정을 위한 빠른 콘텐츠 분석 |

휴대전화에서는 설정의 각 선택기 아래에 선택한 모델의 전체 설명(가격, « 권장 » 또는 « 사전 공개 버전 »)이 표시됩니다. 이전에는 메뉴를 닫으면 이 내용이 잘렸습니다.

## 빠른 시작

```bash
# Cloner le dépôt
git clone https://github.com/jls42/EurekAI.git

# Installer les dépendances

# Configurer les clés API
cp .env.example .env

#   MISTRAL_API_KEY=<your_api_key>           (optionnel — sinon chaque utilisateur saisit sa clé dans l'app)
#   SONAR_TOKEN=...                          (optionnel, CI SonarCloud uniquement)

# Lancer le développement
npm run dev
# → Backend :  http://localhost:3000 (API)
# → Frontend : http://localhost:5173 (serveur Vite avec HMR)
```

> **참고**: Mistral Voxtral TTS가 유일한 TTS 제공업체이므로 `MISTRAL_API_KEY` 외에 추가 키가 필요하지 않습니다.

> **사용자가 입력하는 API 키**: `MISTRAL_API_KEY`은 이제 **선택 사항**입니다. 키가 없어도 앱은 시작되며, 각 사용자에게 인터페이스에서 **자신의 Mistral 키**를 입력하도록 안내합니다. 키는 **브라우저에 저장**되며(보안 컨텍스트에서 Web Crypto + IndexedDB로 암호화), 요청마다 전송됩니다. **서버에는 절대 영구 저장되지 않습니다**. 우선순위: 프로필 키 > 브라우저 전역 키 > `MISTRAL_API_KEY`(환경 변수). `EUREKAI_REQUIRE_USER_KEY=true`을 설정하면 모든 사용자가 자신의 키를 제공해야 합니다(환경 변수의 키는 사전 로드에만 사용됨).

> **로컬 HTTPS(태블릿/LAN)**: `localhost`은 이미 보안 컨텍스트입니다. LAN으로 접속하려면(태블릿) 로컬 인증서를 생성하고 HTTPS를 활성화하세요. 그러면 브라우저가 저장하는 키를 암호화할 수 있으며, 전송 중에도 키가 암호화됩니다.
> ```bash
> ./scripts/gen-cert.sh 192.168.1.42   # mkcert si dispo, sinon openssl self-signed
> export HTTPS_KEY=certs/key.pem HTTPS_CERT=certs/cert.pem
> npm run dev                          # Express + Vite en HTTPS
> ```

### 환경 변수

| 변수 | 필수 여부 | 기본값 | 역할 |
|---|---|---|---|
| `MISTRAL_API_KEY` | 선택 사항 | — | Mistral API 키(채팅, OCR, STT, Voxtral TTS, 에이전트, 콘텐츠 검토). 없으면 사용자가 앱에서 자신의 키를 입력합니다(브라우저에 저장되며 서버에는 저장되지 않음). |

## 아키텍처 결정

| 결정 | 근거 |
|---|---|
| **React/Vue 대신 Alpine.js** | 최소한의 용량, Vite로 컴파일한 TypeScript를 통한 가벼운 반응성. 속도가 중요한 해커톤에 적합합니다. |
| **JSON 파일에 영구 저장** | 의존성이 없고 즉시 시작할 수 있습니다. 데이터베이스를 설정할 필요 없이 실행하면 바로 사용할 수 있습니다. |
| **Vite + Handlebars** | 두 도구의 장점을 결합: 개발 시 빠른 HMR, 코드 구성을 위한 HTML 부분 템플릿, Tailwind JIT. |
| **프롬프트 중앙 관리** | 모든 인공지능 프롬프트를 `prompts.ts`에서 관리 — 반복 개선, 테스트, 언어/연령대별 조정이 쉽습니다. |
| **다중 생성 시스템** | 각 생성 결과는 고유한 ID를 가진 독립 객체입니다 — 강좌마다 여러 복습 자료, 퀴즈 등을 만들 수 있습니다. |
| **연령별 맞춤 프롬프트** | 어휘, 복잡도, 어조가 다른 4개 연령대 — 같은 내용도 학습자에 따라 다르게 가르칩니다. |
| **에이전트 기반 기능** | 이미지 생성과 웹 검색에 임시 Mistral 에이전트를 사용합니다 — 자동 정리로 수명 주기를 깔끔하게 관리합니다. |
| **지능형 URL 스크래핑** | 하나의 입력란에 URL과 키워드를 함께 입력할 수 있습니다 — URL은 Readability (정적 페이지)로 스크래핑하며 필요하면 Lightpanda (JS/SPA 페이지)를 사용하고, 키워드는 Mistral web_search 에이전트를 실행합니다. 각 결과는 독립적인 소스로 생성됩니다. |
| **100% Mistral TTS** | Mistral Voxtral TTS (`MISTRAL_API_KEY` 외에 추가 키가 필요하지 않음) — 음성 합성을 비용 처리 흐름 및 언어별 음성 선택에 통합했습니다. |

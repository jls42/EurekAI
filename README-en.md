## The Story — Why EurekAI?

**EurekAI** was born during the [Mistral AI Worldwide Hackathon](https://luma.com/mistralhack-online) ([official website](https://worldwide-hackathon.mistral.ai/)) (March 2026). I needed a project topic — and the idea came from something very practical: I regularly study for tests with my daughter, and I thought it should be possible to make it more fun and interactive using AI.

The goal: take **any input** — a photo of a lesson, pasted text, a voice recording, a web search — and turn it into **study sheets, flashcards, quizzes, podcasts, fill-in-the-blanks, illustrations, and more**. All powered by French models from Mistral AI, making it naturally tailored for French-speaking students.

The [initial prototype](https://github.com/jls42/worldwide-hackathon.mistral.ai) was built in 48 hours during the hackathon as a proof of concept around Mistral services — already functional, but limited. Since then, EurekAI has grown into a full-fledged project: fill-in-the-blanks, exercise navigation, web scraping, configurable parental moderation, thorough code reviews, and much more. All the code was generated by AI — primarily [Claude Code](https://code.claude.com/), with some contributions via [Codex](https://openai.com/codex/) and [Gemini CLI](https://geminicli.com/).

## Deep Dive — Features

### Multimodal Input

EurekAI accepts 4 types of sources, moderated according to the profile (enabled by default for child and teen):

- **File Import** — JPG, PNG, or PDF files processed by Mistral OCR — **OCR 4 (`mistral-ocr-4-0`) by default** (best quality), **OCR 3 (`mistral-ocr-2512`) optional** in Settings (cheaper, ~½ the cost) — for printed text, tables, and handwriting; or text files (TXT, MD) imported directly. Multi-file uploads use an **upload session** system: individual progress per file, retry for failed files without re-submitting others, session dismissal when finished. OCR exposes an averaged **confidence score** (`average`, clamped to `[0,1]`, calculated from `averagePageConfidenceScore` returned by Mistral), displayed in the UI as a tier badge `high` / `medium` / `low` (thresholds ~0.9 / ~0.7) — warns without blocking if the scan is of poor quality. The copy of the document sent to Mistral for OCR is deleted as soon as processing finishes, even in case of failure.
- **Free Text** — Type or paste any content. Moderated before storage if moderation is active.
- **Voice Input** — Record audio in the browser. Transcribed by `voxtral-mini-latest`. The `language="fr"` parameter optimizes recognition.
- **Web / URL** — Paste one or more URLs to scrape content directly (Readability + Lightpanda for JS pages), or type keywords for a web search via Mistral Agent. The single input field accepts both — URLs and keywords are automatically separated, with each result creating an independent source.

### AI Content Generation

Eight types of generated learning materials:

| Generator | Model | Output |
|---|---|---|
| **Study Sheet** | `mistral-large-latest` | Title, summary, key points, vocabulary, quotes, trivia |
| **Flashcards** | `mistral-large-latest` | Q&A cards with source references (configurable count) |
| **MCQ Quiz** | `mistral-large-latest` | Multiple-choice questions, explanations, adaptive review (configurable count) |
| **Fill-in-the-blanks** | `mistral-large-latest` | Sentences to complete with hints, tolerant validation (Levenshtein) |
| **Dictation** | `mistral-large-latest` + Voxtral TTS | Key words dictated in audio (1 MP3/word) → keyboard input → strict correction (accents) with explained rule |
| **Podcast** | `mistral-large-latest` + Voxtral TTS | Two-voice script → MP3 audio |
| **Illustration** | Agent `mistral-large-latest` | Educational image via the `image_generation` tool |
| **Voice Quiz** | `mistral-large-latest` + Voxtral TTS + STT | TTS questions → STT answer → AI verification |

### AI Chat Tutor

A conversational tutor with full access to course documents:

- Uses `mistral-large-latest`
- **Tool Calling**: can generate study sheets, flashcards, quizzes, or fill-in-the-blanks during the conversation
- History of 50 messages per course
- Moderation if enabled for the profile: messages are checked, and flagged, errored, or not-yet-verified sources are excluded from both context and tools (their verification is first re-triggered, 5 s max)

### Automatic Router

The router uses `mistral-small-latest` to analyze source content and suggest the most relevant generators among the 8 available. The interface displays progress in real time: first an analysis phase, then individual generations with cancellation support.

### Adaptive Learning

- **Quiz Statistics**: tracking attempts and accuracy per question
- **Quiz Review**: generates 5–10 new questions targeting weak concepts, based on the original quiz's sources (moderation guard covers these same sources)
- **Assignment Instruction Detection**: detects study instructions ("I know my lesson if I can...") and prioritizes them in compatible text generators (sheet, flashcards, quiz, fill-in-the-blanks). When moderation is active, detection waits for source verification and reads only those deemed safe; the instruction keeps the list of its origin sources, is neither displayed nor applied if any of them becomes flagged, and disappears along with it. Its cost is tracked

### Safety & Parental Controls

- **4 age groups**: child (≤10 years), teen (11–15), student (16–25), adult (26+)
- **Content Moderation**: `mistral-moderation-2603` (Mistral Moderation 2) with 11 available categories, 6 blocked by default for new child/teen profiles (`sexual`, `hate_and_discrimination`, `violence_and_threats`, `criminal`, `selfharm`, `jailbreaking`; `criminal` added after testing on 50 lessons, including history, without any false positive). Categories customizable per profile in settings; Moderation 2 split the former "dangerous content" category into `dangerous` + `criminal` (existing profiles are migrated automatically, and blocked categories also apply to already imported sources). Safe by default: if the model response does not allow checking a blocked category, the content is rejected ("Moderation unavailable"); with active moderation, both generation and chat exclude flagged, errored, or pending-verification sources. A source that was never verified (imported with moderation off, legacy attached project) is verified before use; moderation interrupted by a restart or failed with an error is automatically resumed (at startup if the server key allows, otherwise when opening the project or during the next generation), and a "Check again" button restarts it on demand. Content of a flagged or pending-verification source is hidden from the child (preview, text, original document); a parent can display it with their PIN for a single consultation. The oral response in the voice quiz is moderated before being evaluated. Dated ID pinned in `helpers/moderation-model.ts`: the deprecated `-latest` alias is no longer listed by the API.
- **Parental PIN**: SHA-256 hash, required for profiles under 15 years old; max 10 incorrect attempts per 15 minutes per IP address (429 `rate_limited`). For a production deployment, use a slow salted hash (Argon2id, bcrypt).
- **Server Data**: `/output` only serves project media (audio, images, imported files); `profiles.json`, `config.json`, and project files are never served
- **Chat Restrictions**: AI chat disabled by default for under 16s, can be enabled by parents

### Multi-Profile System

- Multiple profiles with name, age, avatar, language preferences
- **Voice per Profile** (`Profile.mistralVoices?: { host?, guest? }` — each role is optional) — each child can have their own podcast/voice quiz voice pair
- **Theme per Profile** (`Profile.theme: 'dark' | 'light'`) — automatic switch on profile change, persisted on the backend
- Projects linked to profiles via `profileId`; a legacy project without a profile is attached to the first profile that opens it, then moderated according to that profile
- Cascade deletion: deleting a profile deletes all its projects

### API Cost Tracking

Every billable Mistral call (chat, OCR, STT, TTS, agents), including instruction detection and voice quiz oral responses, is instrumented to provide a **transparent** € estimate to the user. Moderation, being free, is not counted. Agent tool fees are included: $0.03 per web search and $0.10 per generated image (Mistral rates), plus tokens produced by these tools, counted at the agent model's input rate.

- **Source of truth**: `helpers/pricing.ts` — `MODEL_PRICING` per model prefix (e.g.: `mistral-large` → input 0.5 €/M tokens, output 1.5 €/M tokens), `PRICING_SOURCES` with Mistral doc URLs for periodic re-scraping
- **Supported units**: `tokens`, `characters` (TTS), `pages` (OCR), `audio-seconds` (STT) — conversion driven by `helpers/cost-calc.ts`
- **Instrumentation pipeline**: `helpers/tracked-client.ts` (Mistral client wrap) → `helpers/usage-context.ts` (AsyncLocalStorage) → `helpers/cost-calc.ts` → `helpers/cost-persist.ts` → `helpers/cost-middleware.ts` (injection into the HTTP response)
- **UI**: cost badge per generation (`src/partials/cost-badge-gen.html`), per source (`cost-badge-src.html`), cumulative total in the dashboard (`Project.totalCost`)
- **Endpoints**: `/generate/*` and `/sources/*` responses decorate the returned object (Generation / Source) with `estimatedCost`, `usage`, and `costBreakdown`. `POST /generate/route` adds a `costDelta: number` field for the routing cost alone; `POST /detect-consigne` (`{consigne, costDelta}`) and oral response verification also return their `costDelta`. `GET /projects/:pid` returns the project enriched with `totalCost` (sum calculated from `costLog[]`) + complete history

### TTS (Mistral Voxtral) & Custom Voices

- **Mistral Voxtral TTS**: `voxtral-mini-tts-latest`, 100% Mistral speech synthesis, no additional key required
- **Custom voices**: parents can create their own voices via the Mistral Voices API (from an audio sample) and assign them to host/guest roles — podcasts and voice quizzes are then read in a parent's voice, making the experience even more immersive for the child
- Two configurable voice roles: **host** (primary narrator) and **guest** (second podcast voice)
- Full Mistral voice catalog available in settings, filterable by language

### Internationalization

- Interface available in 9 languages: fr, en, es, pt, it, nl, de, hi, ar
- AI prompts support 15 languages (fr, en, es, de, it, pt, nl, ja, zh, ko, ar, hi, pl, ro, sv)
- Configurable language per profile

## Quick Start

```bash
# Cloner le dépôt
git clone https://github.com/jls42/EurekAI.git
cd EurekAI

# Installer les dépendances
npm install

# Configurer les clés API
cp .env.example .env
# Éditez .env (toutes optionnelles) :
#   MISTRAL_API_KEY=<your_api_key>           (optionnel — sinon chaque utilisateur saisit sa clé dans l'app)
#   SONAR_TOKEN=...                          (optionnel, CI SonarCloud uniquement)

# Lancer le développement
npm run dev
# → Backend :  http://localhost:3000 (API)
# → Frontend : http://localhost:5173 (serveur Vite avec HMR)
```

> **Note**: Mistral Voxtral TTS is the only TTS provider — no additional key required beyond `MISTRAL_API_KEY`.

> **User-entered API key**: `MISTRAL_API_KEY` is now **optional**. If absent, the app still starts and prompts each user to enter **their own Mistral key** in the interface. The key is **stored in the browser** (encrypted via Web Crypto + IndexedDB in a secure context) and sent per request — **never persisted on the server**. Precedence: profile key > global browser key > `MISTRAL_API_KEY` (env). Setting `EUREKAI_REQUIRE_USER_KEY=true` forces each user to provide their key (the env key is then only used for preloads).

> **Local HTTPS (tablet/LAN)**: `localhost` is already a secure context. For LAN access (tablet), generate a local certificate and enable HTTPS to unlock browser encryption + encrypt the key in transit:
> ```bash
> ./scripts/gen-cert.sh 192.168.1.42   # mkcert if available, otherwise openssl self-signed
> export HTTPS_KEY=certs/key.pem HTTPS_CERT=certs/cert.pem
> npm run dev                          # Express + Vite over HTTPS
> ```

### Environment Variables

| Variable | Required | Default | Role |
|---|---|---|---|
| `MISTRAL_API_KEY` | optional | — | Mistral API key (chat, OCR, STT, Voxtral TTS, agents, moderation). If absent, the user enters their key in the app (stored in browser, never on server) |
| `EUREKAI_REQUIRE_USER_KEY` | optional | `false` | `true` → disables fallback to `MISTRAL_API_KEY` for AI requests (each user MUST provide their key). Useful on an exposed instance |
| `HTTPS_KEY` / `HTTPS_CERT` | optional | — | TLS key/cert paths (see `scripts/gen-cert.sh`) → Express and Vite serve over HTTPS (secure context LAN/tablet) |
| `PORT` | optional | `3000` | Express backend HTTP port |
| `NODE_ENV` | optional | `development` | If `production` → Express serves the frontend from `dist/` (otherwise `public/`) |
| `SONAR_TOKEN` | optional CI | — | Used only by the SonarCloud GitHub Actions workflow |

## Container Deployment

The image is published on **GitHub Container Registry**:

```bash
# Télécharger l'image
podman pull ghcr.io/jls42/eurekai:latest

# Lancer EurekAI
mkdir -p ./data
podman run -d --name eurekai \
  -e MISTRAL_API_KEY=<your_api_key> \
  -v ./data:/app/output:U \
  -p 3000:3000 \
  ghcr.io/jls42/eurekai:latest
# → http://localhost:3000
```

> **`:U`** is a rootless Podman flag that automatically adjusts volume permissions.

```bash
# Build local
podman build -t eurekai -f Containerfile .

# Publier sur ghcr.io (mainteneurs)
./scripts/publish-ghcr.sh
```

## Architectural Decisions

| Decision | Rationale |
|---|---|
| **Alpine.js rather than React/Vue** | Minimal footprint, lightweight reactivity with TypeScript compiled by Vite. Perfect for a hackathon where speed matters. |
| **JSON file persistence** | Zero dependencies, instant startup. No database to configure — launch and go. |
| **Vite + Handlebars** | Best of both worlds: fast HMR for development, HTML partials for code organization, Tailwind JIT. |
| **Centralized prompts** | All AI prompts in `prompts.ts` — easy to iterate, test, and adapt per language/age group. |
| **Multi-generation system** | Each generation is an independent object with its own ID — allows multiple sheets, quizzes, etc. per course. |
| **Age-adapted prompts** | 4 age groups with different vocabulary, complexity, and tone — the same content teaches differently depending on the learner. |
| **Agent-based features** | Image generation and web search use temporary Mistral Agents — clean lifecycle with automatic cleanup. |
| **Smart URL scraping** | A single field accepts mixed URLs and keywords — URLs are scraped via Readability (static pages) with Lightpanda fallback (JS/SPA pages), keywords trigger a Mistral web_search Agent. Each result creates an independent source. |
| **100% Mistral TTS** | Mistral Voxtral TTS (no additional key beyond `MISTRAL_API_KEY`) — speech synthesis integrated into the cost tracking pipeline and voice resolution per language. |

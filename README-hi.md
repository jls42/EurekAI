## कहानी — EurekAI क्यों?

**EurekAI** का जन्म [Mistral AI Worldwide Hackathon](https://luma.com/mistralhack-online) ([आधिकारिक वेबसाइट](https://worldwide-hackathon.mistral.ai/)) (मार्च 2026) के दौरान हुआ। मुझे एक विषय चाहिए था — और यह विचार एक बेहद व्यावहारिक अनुभव से आया: मैं अपनी बेटी के साथ नियमित रूप से परीक्षाओं की तैयारी करता हूँ, और मुझे लगा कि AI की सहायता से इसे अधिक मनोरंजक और इंटरैक्टिव बनाया जा सकता है।

लक्ष्य: **किसी भी इनपुट** — पाठ की तस्वीर, कॉपी-पेस्ट किया हुआ टेक्स्ट, वॉइस रिकॉर्डिंग या वेब खोज — को **अध्ययन नोट्स, flashcards, quiz, podcasts, रिक्त-स्थान वाले अभ्यास, illustrations और बहुत कुछ** में बदलना। यह सब Mistral AI के फ्रांसीसी models द्वारा संचालित है, जिससे यह स्वाभाविक रूप से फ़्रांसीसी-भाषी विद्यार्थियों के लिए उपयुक्त समाधान बनता है।

[आरंभिक prototype](https://github.com/jls42/worldwide-hackathon.mistral.ai) को hackathon के दौरान 48 घंटों में Mistral सेवाओं पर आधारित अवधारणा-प्रमाण के रूप में बनाया गया था — यह पहले से काम करता था, लेकिन सीमित था। तब से EurekAI एक वास्तविक परियोजना बन चुका है: रिक्त-स्थान वाले अभ्यास, अभ्यासों में navigation, web scraping, विन्यास योग्य parental moderation, विस्तृत code review और बहुत कुछ। पूरा code AI द्वारा तैयार किया गया है — मुख्यतः [Claude Code](https://code.claude.com/), और कुछ योगदान [Codex](https://openai.com/codex/) तथा [Gemini CLI](https://geminicli.com/) के माध्यम से किए गए हैं।

## गहराई से — सुविधाएँ

### Multi-modal इनपुट

EurekAI 4 प्रकार के स्रोत स्वीकार करता है, जिनका profile के अनुसार moderation किया जाता है (बच्चों और किशोरों के लिए default रूप से सक्रिय):

- **फ़ाइल आयात** — Mistral OCR द्वारा संसाधित JPG, PNG या PDF फ़ाइलें — default रूप से **OCR 4 (`mistral-ocr-4-0`)** (बेहतर गुणवत्ता), Settings में वैकल्पिक रूप से **OCR 3 (`mistral-ocr-2512`)** (सस्ता, लगभग आधी लागत) — मुद्रित टेक्स्ट, tables और हस्तलेखन के लिए; या सीधे आयातित टेक्स्ट फ़ाइलें (TXT, MD)। Multi-file uploads में **upload sessions** की व्यवस्था का उपयोग होता है: प्रत्येक फ़ाइल की अलग progress, अन्य फ़ाइलों को फिर से submit किए बिना विफल फ़ाइल का retry, और पूरा होने पर session को dismiss करना। OCR औसत **विश्वास स्कोर** प्रदान करता है (`average`, `[0,1]` में clamp किया गया, Mistral द्वारा लौटाए गए `averagePageConfidenceScore` से परिकलित), जो UI में `high` / `medium` / `low` tier badge के रूप में दिखता है (सीमाएँ लगभग 0.9 / लगभग 0.7) — scan की गुणवत्ता खराब होने पर यह प्रक्रिया रोके बिना चेतावनी देता है। OCR के लिए Mistral को भेजी गई document की प्रति processing समाप्त होते ही हटा दी जाती है, विफलता की स्थिति में भी।
- **मुक्त टेक्स्ट** — कोई भी सामग्री टाइप या पेस्ट करें। Moderation सक्रिय होने पर storage से पहले उसका moderation किया जाता है।
- **वॉइस इनपुट** — Browser में audio रिकॉर्ड करें। `voxtral-mini-latest` द्वारा लिप्यंतरित। `language="fr"` parameter पहचान को बेहतर बनाता है।
- **Web / URL** — सामग्री को सीधे scrape करने के लिए एक या अधिक URLs पेस्ट करें (JS pages के लिए Readability + Lightpanda), या Mistral Agent के माध्यम से web search के लिए keywords लिखें। एक ही field दोनों को स्वीकार करता है — URLs और keywords स्वतः अलग किए जाते हैं, और प्रत्येक result एक स्वतंत्र source बनाता है।

### AI सामग्री निर्माण

निर्मित शिक्षण सामग्री के आठ प्रकार:

| Generator | Model | Output |
|---|---|---|

| **बहुविकल्पीय Quiz** | `mistral-large-latest` | बहुविकल्पीय प्रश्न, व्याख्याएँ, adaptive review (संख्या विन्यास योग्य) |
| **रिक्त-स्थान वाले अभ्यास** | `mistral-large-latest` | संकेतों वाली पूर्ण करने योग्य पंक्तियाँ, उदार सत्यापन (Levenshtein) |
| **श्रुतलेख** | `mistral-large-latest` + Voxtral TTS | Audio में बोले गए मुख्य शब्द (1 MP3/शब्द) → keyboard से प्रविष्टि → समझाए गए नियम के साथ सख़्त सुधार (मात्राएँ) |
| **Podcast** | `mistral-large-latest` + Voxtral TTS | 2 आवाज़ों वाला script → MP3 audio |
| **Illustration** | Agent `mistral-large-latest` | `image_generation` tool के माध्यम से शैक्षिक image |
| **वॉइस Quiz** | `mistral-large-latest` + Voxtral TTS + STT | TTS प्रश्न → STT उत्तर → AI सत्यापन |

### Chat द्वारा AI शिक्षक

पाठ्यक्रम के documents तक पूर्ण पहुँच वाला संवादात्मक शिक्षक:

- `mistral-large-latest` का उपयोग करता है
- **Tool calling**: बातचीत के दौरान अध्ययन नोट्स, flashcards, quiz या रिक्त-स्थान वाले अभ्यास बना सकता है
- प्रत्येक पाठ्यक्रम के लिए 50 messages का इतिहास
- Profile के लिए सक्रिय होने पर moderation: message की जाँच की जाती है, और चिह्नित, त्रुटिपूर्ण या अभी तक असत्यापित sources को context तथा tools से बाहर रखा जाता है (पहले उनकी जाँच फिर से शुरू की जाती है, अधिकतम 5 सेकंड)

### स्वचालित Router

Router sources की सामग्री का विश्लेषण करने और उपलब्ध 8 विकल्पों में से सबसे प्रासंगिक generators सुझाने के लिए `mistral-small-latest` का उपयोग करता है। Interface वास्तविक समय में progress दिखाता है: पहले analysis चरण, फिर अलग-अलग निर्माण, जिन्हें रद्द किया जा सकता है।

### Adaptive learning

- **Quiz आँकड़े**: प्रत्येक प्रश्न के attempts और accuracy की निगरानी
- **Quiz review**: मूल quiz के sources के आधार पर कमज़ोर अवधारणाओं पर केंद्रित 5-10 नए प्रश्न बनाता है (moderation guard इन्हीं sources पर लागू होता है)
- **निर्देश की पहचान**: समीक्षा संबंधी निर्देशों ("यदि मुझे यह आता है तो मुझे अपना पाठ आता है...") को पहचानता है और संगत textual generators (अध्ययन नोट्स, flashcards, quiz, रिक्त-स्थान वाले अभ्यास) में उन्हें प्राथमिकता देता है। Moderation सक्रिय होने पर पहचान sources की जाँच पूरी होने की प्रतीक्षा करती है और केवल सुरक्षित माने गए sources को पढ़ती है; निर्देश अपने मूल sources की सूची बनाए रखता है, उनमें से किसी के चिह्नित होने पर न तो दिखाया जाता है, न लागू किया जाता है, और उसके साथ ही गायब हो जाता है। इसकी लागत की गणना की जाती है

### सुरक्षा और parental control

- **4 आयु समूह**: बच्चा (≤10 वर्ष), किशोर (11-15), विद्यार्थी (16-25), वयस्क (26+)
- **सामग्री moderation**: `mistral-moderation-2603` (Mistral Moderation 2), जिसमें 11 उपलब्ध श्रेणियाँ हैं और नए बच्चों/किशोरों के profiles के लिए default रूप से 6 अवरुद्ध हैं (`sexual`, `hate_and_discrimination`, `violence_and_threats`, `criminal`, `selfharm`, `jailbreaking`; इतिहास सहित 50 पाठों पर बिना किसी false positive के माप के बाद `criminal` जोड़ा गया)। Settings में प्रत्येक profile के अनुसार श्रेणियाँ अनुकूलन योग्य हैं; Moderation 2 ने पुरानी « खतरनाक सामग्री » श्रेणी को `dangerous` + `criminal` में विभाजित किया है (मौजूदा profiles स्वतः migrate किए जाते हैं, और अवरुद्ध श्रेणियाँ पहले से आयातित sources पर भी लागू होती हैं)। Default सुरक्षा: यदि model का उत्तर किसी अवरुद्ध श्रेणी की जाँच की अनुमति नहीं देता, तो सामग्री अस्वीकार कर दी जाती है (« Moderation उपलब्ध नहीं »); moderation सक्रिय होने पर निर्माण और chat दोनों चिह्नित, त्रुटिपूर्ण या जाँच की प्रक्रिया में मौजूद sources को बाहर रखते हैं। जिस source की कभी जाँच नहीं हुई (moderation निष्क्रिय रहते आयात किया गया, जुड़ी हुई पुरानी परियोजना), उपयोग से पहले उसकी जाँच की जाती है; restart से बाधित या त्रुटिग्रस्त moderation स्वतः फिर से शुरू होता है (यदि server key अनुमति देती है तो startup पर, अन्यथा परियोजना खोलने या अगले निर्माण पर), और « फिर से जाँचें » बटन माँग पर इसे पुनः शुरू करता है। चिह्नित या जाँच की प्रक्रिया में मौजूद source की सामग्री बच्चे से छिपी रहती है (preview, टेक्स्ट, मूल document); माता-पिता अपने PIN से उसे केवल देखने की अवधि तक प्रदर्शित कर सकते हैं। वॉइस quiz के मौखिक उत्तर को सत्यापित करने से पहले उसका moderation किया जाता है। `helpers/moderation-model.ts` में दिनांकित Id pin किया गया है: deprecated alias `-latest` अब API द्वारा सूचीबद्ध नहीं किया जाता।
- **Parental PIN**: SHA-256 hash, 15 वर्ष से कम आयु वाले profiles के लिए आवश्यक; प्रति IP address हर पंद्रह मिनट में अधिकतम 10 गलत codes (429 `rate_limited`)। Production deployment के लिए salt वाला धीमा hash (Argon2id, bcrypt) रखें।
- **Server data**: `/output` केवल परियोजनाओं के media (audio, images, आयातित फ़ाइलें) प्रकाशित करता है; `profiles.json`, `config.json` और परियोजनाओं की फ़ाइलें कभी serve नहीं की जातीं
- **Chat प्रतिबंध**: 16 वर्ष से कम आयु वालों के लिए AI chat default रूप से निष्क्रिय है, माता-पिता इसे सक्रिय कर सकते हैं

### Multi-profile व्यवस्था

- नाम, आयु, avatar और भाषा प्राथमिकताओं वाले अनेक profiles
- **प्रत्येक profile की आवाज़ें** (`Profile.mistralVoices?: { host?, guest? }` — प्रत्येक भूमिका वैकल्पिक है) — प्रत्येक बच्चे के पास podcast/वॉइस quiz के लिए अपनी आवाज़ों की जोड़ी हो सकती है
- **प्रत्येक profile की theme** (`Profile.theme: 'dark' | 'light'`) — profile बदलने पर स्वतः बदलती है, backend में सुरक्षित रहती है
- Projects `profileId` के माध्यम से profiles से जुड़े होते हैं; profile के बिना किसी पुरानी परियोजना को खोलने वाले पहले profile से जोड़ दिया जाता है, फिर उसी profile के अनुसार उसका moderation होता है
- क्रमिक विलोपन: किसी profile को हटाने से उसकी सभी projects हट जाती हैं
### API लागत की निगरानी

प्रत्येक शुल्क-योग्य Mistral कॉल (chat, OCR, STT, TTS, agents), जिसमें निर्देश की पहचान और ध्वनि प्रश्नोत्तरी के मौखिक उत्तर शामिल हैं, उपयोगकर्ता को € में **पारदर्शी** अनुमान प्रदान करने के लिए इंस्ट्रूमेंट किया गया है। निःशुल्क मॉडरेशन की गणना नहीं की जाती। agents के टूल शुल्क शामिल हैं: प्रत्येक वेब खोज के लिए 0.03 $ और प्रत्येक जनरेट की गई छवि के लिए 0.10 $ (Mistral दरें), साथ ही इन टूल द्वारा उत्पादित tokens, जिनकी गणना agent के मॉडल की इनपुट दर पर की जाती है।

- **सत्य का स्रोत**: `helpers/pricing.ts` — मॉडल prefix के अनुसार `MODEL_PRICING` (उदा.: `mistral-large` → इनपुट 0.5 €/M tokens, आउटपुट 1.5 €/M tokens), Mistral दस्तावेज़ के URLs के साथ `PRICING_SOURCES`, ताकि समय-समय पर पुनः scraping की जा सके
- **समर्थित इकाइयाँ**: `tokens`, `characters` (TTS), `pages` (OCR), `audio-seconds` (STT) — रूपांतरण `helpers/cost-calc.ts` द्वारा नियंत्रित
- **इंस्ट्रूमेंटेशन श्रृंखला**: `helpers/tracked-client.ts` (Mistral client wrapper) → `helpers/usage-context.ts` (AsyncLocalStorage) → `helpers/cost-calc.ts` → `helpers/cost-persist.ts` → `helpers/cost-middleware.ts` (HTTP उत्तर में अंतःक्षेपण)
- **UI**: प्रत्येक generation के लिए लागत badge (`src/partials/cost-badge-gen.html`), प्रत्येक source के लिए (`cost-badge-src.html`), dashboard में संचयी कुल (`Project.totalCost`)
- **Endpoints**: `/generate/*` और `/sources/*` के उत्तर लौटाए गए object (Generation / Source) को `estimatedCost`, `usage` और `costBreakdown` से सजाते हैं। `POST /generate/route` केवल routing लागत के लिए `costDelta: number` field जोड़ता है; `POST /detect-consigne` (`{consigne, costDelta}`) और मौखिक उत्तर का सत्यापन भी अपना `costDelta` लौटाते हैं। `GET /projects/:pid`, `totalCost` से समृद्ध project (`costLog[]` से गणना किया गया योग) और पूरा इतिहास लौटाता है

### TTS (Mistral Voxtral) और कस्टम आवाज़ें

- **Mistral Voxtral TTS**: `voxtral-mini-tts-latest`, 100% Mistral वाक् संश्लेषण, किसी अतिरिक्त key की आवश्यकता नहीं
- **कस्टम आवाज़ें**: अभिभावक Mistral Voices API के माध्यम से (एक audio sample से) अपनी आवाज़ें बना सकते हैं और उन्हें host/guest भूमिकाओं को सौंप सकते हैं — तब podcasts और ध्वनि प्रश्नोत्तरी अभिभावक की आवाज़ में पढ़ी जाती हैं, जिससे बच्चे के लिए अनुभव और भी अधिक तल्लीनकारी बनता है
- दो कॉन्फ़िगर करने योग्य ध्वनि भूमिकाएँ: **host** (मुख्य वाचक) और **guest** (podcast की दूसरी आवाज़)
- Mistral आवाज़ों की पूरी सूची settings में उपलब्ध है और भाषा के अनुसार filter की जा सकती है

## त्वरित शुरुआत

```bash
# Cloner le dépôt
git clone https://github.com/jls42/EurekAI.git
cd EurekAI

# Installer les dépendances
npm install

# Configurer les clés API
cp .env.example .env
# Éditez .env (toutes optionnelles) :
#   MISTRAL_API_KEY=<your_api_key>           (optionnel — sinon chaque utilisateur saisit sa clé dans l'app)
#   SONAR_TOKEN=...                          (optionnel, CI SonarCloud uniquement)

# Lancer le développement
npm run dev
# → Backend :  http://localhost:3000 (API)
# → Frontend : http://localhost:5173 (serveur Vite avec HMR)
```

> **ध्यान दें**: Mistral Voxtral TTS एकमात्र TTS provider है — `MISTRAL_API_KEY` के अतिरिक्त किसी key की आवश्यकता नहीं है।

> **उपयोगकर्ता द्वारा दर्ज API key**: `MISTRAL_API_KEY` अब **वैकल्पिक** है। इसके अनुपस्थित होने पर भी app शुरू हो जाता है और प्रत्येक उपयोगकर्ता को interface में **अपनी Mistral key** दर्ज करने के लिए कहता है। key को **browser में संग्रहीत** किया जाता है (सुरक्षित context में Web Crypto + IndexedDB के माध्यम से encrypted) और प्रत्येक request के साथ भेजा जाता है — **server पर कभी persist नहीं किया जाता**। प्राथमिकता: profile key > browser global key > `MISTRAL_API_KEY` (env)। `EUREKAI_REQUIRE_USER_KEY=true` निर्धारित करने पर प्रत्येक उपयोगकर्ता को अपनी key देनी होगी (env key का उपयोग फिर केवल preload के लिए होगा)।

> **स्थानीय HTTPS (tablet/LAN)**: `localhost` पहले से एक सुरक्षित context है। LAN access (tablet) के लिए, browser encryption सक्रिय करने और transit में key encrypt करने हेतु एक स्थानीय certificate बनाएँ और HTTPS सक्रिय करें:
> ```bash
> ./scripts/gen-cert.sh 192.168.1.42   # mkcert si dispo, sinon openssl self-signed
> export HTTPS_KEY=certs/key.pem HTTPS_CERT=certs/cert.pem
> npm run dev                          # Express + Vite en HTTPS
> ```

| **JSON files में persistence** | शून्य dependency, तुरंत शुरुआत। कॉन्फ़िगर करने के लिए कोई database नहीं — बस शुरू करें और काम चालू। |
| **Vite + Handlebars** | दोनों का सर्वश्रेष्ठ: विकास के लिए तेज़ HMR, code संगठन के लिए HTML partials, Tailwind JIT। |
| **केंद्रीकृत Prompts** | सभी AI prompts `prompts.ts` में — प्रत्येक भाषा/आयु वर्ग के अनुसार पुनरावृत्ति, परीक्षण और अनुकूलन आसान। |
| **Multi-generation प्रणाली** | प्रत्येक generation अपने ID वाला स्वतंत्र object है — प्रत्येक पाठ्यक्रम के लिए कई अध्ययन-पत्र, प्रश्नोत्तरी आदि की अनुमति देता है। |
| **आयु-अनुकूल Prompts** | अलग शब्दावली, जटिलता और स्वर वाले 4 आयु वर्ग — वही सामग्री शिक्षार्थी के अनुसार अलग तरीके से पढ़ाती है। |
| **Agents पर आधारित सुविधाएँ** | Image generation और वेब खोज अस्थायी Mistral Agents का उपयोग करते हैं — स्वचालित cleanup के साथ सुव्यवस्थित lifecycle। |
| **बुद्धिमान URL scraping** | एक ही field मिश्रित URLs और keywords स्वीकार करता है — URLs को Readability (स्थिर pages) के माध्यम से scrape किया जाता है, Lightpanda fallback (JS/SPA pages) के साथ; keywords एक Mistral web_search Agent को trigger करते हैं। प्रत्येक result एक स्वतंत्र source बनाता है। |
| **100% Mistral TTS** | Mistral Voxtral TTS (`MISTRAL_API_KEY` के अतिरिक्त कोई key नहीं) — लागत श्रृंखला और भाषा के अनुसार आवाज़ resolution में एकीकृत वाक् संश्लेषण। |

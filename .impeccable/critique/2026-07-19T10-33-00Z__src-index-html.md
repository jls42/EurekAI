## Anti-Patterns Verdict

**Assessment LLM** : pas de slop structurel. C'est un vrai système tenu — tokens light/dark complets, radius signature, dégradé strictement cantonné à ses 3 usages réservés, glass sur le chrome (une exception : dialogs), code couleur des 8 générateurs cohérent partout, aucun bouton imbriqué. Les tells restants sont localisés : **side-stripes `border-l-4 border-l-gen-*` sur les gen-cards des 8 vues** (pattern banni, redondant avec l'icon-chip), **eyebrows uppercase trackés** répétés sur chaque carte du dashboard et chaque message du chat, écran de fin **copié-collé ×4** déjà divergent, empty states en **pastels Tailwind bruts** (3 sans override dark), ternaires `:class` de 300+ caractères ×5 (toolbar audio), et la **fuite de plomberie IA** (prompt d'ingénierie et markdown bruts affichés) — le tell AI-product par excellence.

**Détecteur (CLI, 23 findings, exit 2)** : side-tab ×8 (les mêmes border-l-4 — convergence A/B), design-system-font-size ×8 (10-11px hors ramp, advisory : micro-badges), gray-on-color ×2, bounce-easing ×2, border-accent-on-rounded ×2, flat-type-hierarchy ×1. **6 faux positifs raisonnés** : les gray-on-color sont des branches exclusives de ternaires Alpine, les bounce-easing matchent la keyframe custom `bounce-icon` (ease-in-out, pas le bounce Tailwind), les border-accent sont des soulignements d'input de dictée/fill-blank.

**Overlay navigateur (26 findings sur 4 vues, injection réussie, serveur overlay arrêté)** : recoupe l'Assessment A au dixième — low-contrast 4.2:1 sur le sous-titre #777, thin-border-wide-shadow sur sidebars et 6 dialogs, skipped-heading (h2→h4 dans podcast), layout-transition `width` sur la sidebar, tiny-text 11px. Les hits « gradient-text » sur h1/h2 sont conformes aux 3 usages réservés du DESIGN.md → faux positifs au regard du système.

## Overall Impression

L'app a une âme et un vrai système — le North Star « L'Étincelle » existe déjà à l'écran : ciel calme, couleurs de générateurs comme repères, feedback qui célèbre. Les 5 agents convergent sur le même verdict : **la fondation est bonne, mais l'app parle trop souvent sa langue de machine au lieu de celle de Zoé**. Les trois fuites systémiques : l'argent partout sur l'écran de l'enfant, le jargon technique (jusqu'au prompt d'ingénierie affiché), et des contrastes en échec AA précisément sur les moments pédagogiques clés (écrans de score à 1,76:1). La plus grosse opportunité : une passe « double audience » qui sépare ce que voit l'enfant de ce que gère le parent.

## What's Working

- **Le code couleur des générateurs** est un vrai langage appris : icon-chips, boutons, chips de nav — le repère de Zoé, cohérent sur les 13 surfaces.
- **La copy d'entrée est exemplaire** : « Qui apprend aujourd'hui ? », « Qu'est-ce que tu veux apprendre ? » — tutoiement, premier geste évident en <5s (Jordan validé).
- **Des attentions rares** : bouton FALC « Version très facile à lire », audio par section avec playlist, confort de lecture Luciole par profil, consigne réversible, 6 statuts d'upload en texte+icône jamais couleur seule, citations ancrées anti-hallucination.
- **La discipline du système** : dégradé signature jamais débordé de ses 3 usages, double focus-ring, min-h-touch généralisé, PIN parental réel sur les toggles sensibles.

## Priority Issues

**[P1] Contrastes AA en échec sur les moments pédagogiques clés.** La paire `warning-dark` sur `warning-light` affiche l'écran de score non parfait à **1,76:1** (mesuré, seuil 4,5:1) dans les 4 vues interactives à la fois (écran copié ×4) ; le CTA « M'entraîner sur mes erreurs » est à 1,93:1 ; le dos des flashcards (LA réponse à lire) à 2,89:1 ; les CTAs récurrents blanc-sur-#1cb0f6 à ~2,44:1 ; les chips de nav #777 à 4,25:1 light / 3,40:1 dark ; la bannière d'échec consigne à 1,76:1. Le token `--color-warning-dark` est défectueux pour tout usage texte. → **Fix** : corriger les paires de tokens (texte encre/hue-profond sur fonds pâles), factoriser l'écran de fin en un partial unique, appliquer la Règle de l'Aplat Vif aux CTAs. `/impeccable colorize`

**[P1] Le jargon technique fuit dans l'UI enfant.** « Nécessite MISTRAL_API_KEY pour activer le TTS Voxtral » (tooltips de 3 vues + dashboard), « Configurez MISTRAL_API_KEY dans le fichier .env » (état vide podcast, en vouvoiement), « vérifiez la console » (toast), le **prompt d'ingénierie complet** dans l'accordéon « Prompt used » de view-image (« RAPPEL CRUCIAL — INTERDICTION TOTALE DE TEXTE… »), le **markdown brut avec astérisques littéraux** dans le dialog consigne, les clés `batch`/`key_points` dans le popover de coût. → **Fix** : messages enfant (« Demande à un adulte d'activer le son dans les Réglages ») + CTA parent vers le dialog clé API, rendre/stripper le markdown, résumé humain à la place du prompt. `/impeccable clarify`

**[P1] L'argent domine l'écran de l'enfant.** 9 badges « Est. ~$0.0039 » + « Est. Total: ~$0.5058 » (4 décimales, en dollars alors que le produit promet des €) sur le dashboard de Zoé — violation frontale du principe « l'enfant d'abord ». → **Fix** : masquer les coûts pour les profils enfant ou les replier dans une zone parent unique et discrète. `/impeccable distill`

**[P1] Hover-only = inexistant sur tablette (le device principal).** Les 3 popovers méta (coût, confiance OCR, modération) sont `@mouseenter`-only sur des spans non focusables ; les boutons éditer/supprimer des profils et des cours sont `opacity-0 group-hover` (au tactile, **supprimer un cours est impossible**) ; Tab atteint des boutons invisibles. → **Fix** : popovers togglés clic/Enter, actions visibles en pointeur coarse ou menu ⋯, `group-focus-within`. `/impeccable harden`

**[P1] Modèle de sécurité parentale incohérent.** Le PIN gate les toggles modération/chat… mais l'engrenage du header ouvre les Réglages **sans aucun PIN** : l'enfant peut changer de modèle IA, ouvrir la clé API et taper « Reset » — qui **POSTe `/api/config/reset` immédiatement, sans confirmation**. L'édition de profil (1 clic depuis l'avatar) fait lire à l'enfant « Sexual content, Self-harm, Jailbreaking ». → **Fix** : gater Réglages par le même `requirePin`, confirmation sur Reset (dialog-confirm existe), section « Espace parent » repliée+gatée. `/impeccable harden`

**[P1] Le mobile 390px casse la promesse tablette.** La nav devient 11 chips **icône-seule de 40×32px** sans label (une lectrice débutante doit mémoriser 11 pictos) ; les corbeilles de suppression tombent à 28×28px collées aux crayons ; l'écran « My Scores » — dont c'est la seule raison d'être — n'agrège que le quiz (la dictée T1: 6/9 visible ailleurs n'y figure pas) et n'existe pas en desktop. → **Fix** : chips icône+label ≥44px scrollables, cibles destructives 44px, agrégation de toutes les activités scorées. `/impeccable adapt`

**[P1] L'app blâme l'enfant pour ses propres pannes.** Au quiz vocal, une erreur réseau de vérification est rendue comme une **mauvaise réponse** (boîte rouge « Mauvaise réponse » + « Erreur de vérification ») et le micro ne réapparaît pas ; la flip-card des flashcards est un `<div @click>` sans tabindex/role — l'exercice entier est inaccessible au clavier. → **Fix** : état d'erreur distinct neutre + bouton Réessayer ; `role="button" tabindex="0" @keydown` (pattern gen-card-header existant). `/impeccable harden`

## Persona Red Flags

**Zoé (9 ans, lectrice débutante)** : l'argent est le concept le plus répété de son dashboard ; elle peut lire « Sexual content, Self-harm » en 1 clic depuis son avatar ; le badge rouge « 14 » permanent sur la cloche est une pression continue contraire au « zéro culpabilisation » ; en revenant elle atterrit en plein « Exercise 1/10 · Score: 0 » rouge au lieu d'un accueil.

**Le Parent** : « API Status: 🟢 Mistral » au-dessus de « No key configured » — impossible de savoir qui paye ; le choix de modèle exige de comprendre « $0.50/$1.50 per M tokens » ; sur tablette il ne peut ni éditer un profil depuis le picker ni supprimer un cours ; aucune aide « où trouver ma clé Mistral » (LE mur d'onboarding). Positif : l'explainer « ta clé reste dans ce navigateur » est exemplaire.

**Sam (a11y)** : popover de coût sauté par Tab ; flip-card infranchissable ; état du chat distingué par la couleur seule ; « Listen to the word » blanc sur #0284c7 à 4,1:1. Positif : double focus-ring net, aria-labels sur la cloche, Escape global.

**Casey (tablette une main)** : les popovers hover n'existent pas pour elle ; corbeilles 28px = suppression accidentelle plausible ; chips de nav en haut de l'écran, hors zone du pouce. Positif : min-h-touch généralisé, état préservé entre sessions.

## Minor Observations

Double rangée nav (11 chips) + stats (10 pills quasi identiques) à fusionner ; sélecteur de count à 5 options où 3 suffisent ; « Dashboard » en sous-titre redondant ; fallbacks x-text en anglais dans une app FR ; eyebrows uppercase sur chaque carte ; dialogs contenu (source, consigne) en glass contre la Règle du Chrome de Verre ; radii ad hoc (0.7/0.75/1rem) hors échelle ; boutons Sauvegarder/Reset dans la zone scrollable du dialog Réglages ; typo « Cle API » ; notifications « Image complete » / « 14 d ago » hors voix de marque ; transition `width` sur la sidebar (layout property) ; h2→h4 dans view-podcast.

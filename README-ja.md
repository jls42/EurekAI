## 誕生の背景 — なぜ EurekAI なのか？

**EurekAI** は、[Mistral AI Worldwide Hackathon](https://luma.com/mistralhack-online)（[公式サイト](https://worldwide-hackathon.mistral.ai/)）（2026年3月）で誕生しました。テーマを探していた私にアイデアを与えたのは、とても身近な経験でした。普段から娘と一緒にテスト勉強をしていて、AI を使えば、もっと楽しく対話的にできるはずだと考えたのです。

目標は、授業の写真、コピー＆ペーストした文章、音声録音、ウェブ検索など、**どんな入力でも**、**復習シート、フラッシュカード、クイズ、ポッドキャスト、穴埋め問題、イラストなど**に変えることです。すべてをフランス企業 Mistral AI のモデルで実現しているため、EurekAI はフランス語圏の生徒に自然に適したソリューションとなっています。

[初期プロトタイプ](https://github.com/jls42/worldwide-hackathon.mistral.ai)は、ハッカソンの48時間で Mistral のサービスを使った概念実証として開発しました。すでに動作していましたが、機能は限られていました。それ以来、EurekAI は本格的なプロジェクトへと成長しました。穴埋め問題、演習内の移動、ウェブスクレイピング、設定可能な保護者向けモデレーション、詳細なコードレビューなど、多くの機能を備えています。コードはすべて AI が生成しており、主に [Claude Code](https://code.claude.com/) を使用し、一部では [Codex](https://openai.com/codex/) と [Gemini CLI](https://geminicli.com/) も活用しています。

## 詳しく見る — 機能

### マルチモーダル入力

EurekAI は4種類の資料に対応し、プロフィールに応じてモデレーションを行います（子どもと10代のプロフィールでは、標準でモデレーションが有効です）。

- **ファイルの取り込み** — JPG、PNG、PDF ファイルを Mistral OCR で処理します。標準では **OCR 4.1**（`mistral-ocr-4-1`）を使用し、設定で **OCR 3**（`mistral-ocr-2512`）も選択できます（料金は約½で、手書き文字の読み取りに優れています）。印刷文字、表、手書き文字に対応し、テキストファイル（TXT、MD）は直接取り込めます。複数ファイルのアップロードには**アップロードセッション**を使用し、ファイルごとの進捗表示、ほかのファイルを再送せずに失敗したファイルだけを再試行する機能、完了したセッションを閉じる機能を備えています。OCR は平均**信頼度スコア**（`average`、`[0,1]` の範囲に制限、Mistral が返す `averagePageConfidenceScore` から算出）を提供し、画面に `high` / `medium` / `low` の段階別バッジで表示します（しきい値は約0.9 / 約0.7）。スキャン品質が低い場合も処理を止めずに警告します。OCR のために Mistral に送信した文書のコピーは、処理が失敗した場合も含め、処理終了時に削除されます。
- **自由入力テキスト** — 任意の内容を入力または貼り付けできます。モデレーションが有効な場合は、保存前にチェックします。
- **音声入力** — ブラウザーで音声を録音します。標準では **Voxtral Mini Transcribe 2**（`voxtral-mini-2602`）で文字起こしし、設定で **Voxtral Mini Transcribe 3** と **Voxtral Small Transcribe 3**（Mistral プレビュー版）も選択できます。認識精度を高めるため、インターフェースの言語をモデルに渡します（`language`）。
- **ウェブ / URL** — 1つ以上の URL を貼り付けて内容を直接スクレイピングするか（Readability + JavaScript ページ向けの Lightpanda）、キーワードを入力して Mistral エージェントでウェブ検索します。1つの入力欄が両方に対応し、URL とキーワードを自動的に分離して、結果ごとに独立した資料を作成します。

### AI によるコンテンツ生成

8種類の学習教材を生成します。

| 生成機能 | モデル | 出力 |
|---|---|---|
| **復習シート** | `mistral-large-2512` | タイトル、要約、要点、語彙、引用、豆知識 |
| **フラッシュカード** | `mistral-large-2512` | 出典への参照付きの質問・回答カード（枚数を設定可能） |
| **多肢選択クイズ** | `mistral-large-2512` | 正解が1つの4択問題、解説、適応型復習（問題数を設定可能） |
| **穴埋め問題** | `mistral-large-2512` | ヒント付きの穴埋め文、多少の違いを許容する判定（レーベンシュタイン距離） |
| **書き取り** | `mistral-large-2512` + Voxtral TTS | 重要単語を音声で読み上げ（1 MP3/単語）→ キーボードで入力 → 規則の解説付きで厳密に採点（アクセント記号の付け忘れも誤りとして扱う） |
| **ポッドキャスト** | `mistral-large-2512` + Voxtral TTS | 2人の声による台本 → MP3 音声 |
| **イラスト** | エージェント `mistral-large-2512` | `image_generation` ツールによる学習用画像 |
| **音声クイズ** | `mistral-large-2512` + Voxtral TTS + STT | TTS による問題読み上げ → STT による回答認識 → AI による確認 |

### チャット型 AI チューター

授業資料全体にアクセスできる対話型チューターです。

- `mistral-large-2512` を使用
- **ツール呼び出し**：会話中に復習シート、フラッシュカード、クイズ、穴埋め問題を生成可能
- コースごとに50件のメッセージ履歴を保持
- プロフィールでモデレーションが有効な場合：メッセージをチェックし、問題が報告された資料、チェックに失敗した資料、未チェックの資料をコンテキストとツールの対象から除外します（チェックに失敗した資料と未チェックの資料は、まず最大5 s の再チェックを行います）

### 自動ルーター

ルーターは `mistral-small-latest` を使って資料の内容を分析し、利用可能な8種類から最適な生成機能を提案します。画面には進捗がリアルタイムで表示され、まず分析段階、その後に個々の生成処理が続き、途中でキャンセルもできます。

自動生成はサーバー上で動作します。ページを再読み込みした場合、別のコースを開いた場合、プロフィールを切り替えた場合も継続し、各コースで同時に実行される自動生成は1つだけです（2つ目のタブは実行中の処理に接続します）。サーバーは Mistral キーごとに最大3件の生成を同時に実行します。生成が1件完了するたびにメッセージを表示し、最後に結果のまとめを1回だけ表示します。別のコースを表示中に完了した場合は、メッセージにコース名が表示されます。個別にキャンセルした生成は、結果のまとめで失敗として数えません。「すべてキャンセル」はそのコースの処理全体を停止し、メッセージを1件だけ表示します。自動生成中にサーバーが再起動した場合は、中断されたことを示し、「再開」ボタンを表示します。このボタンは分析をやり直さず、未完了の生成だけを再実行します。

タブから開始した時間のかかる生成処理（個別に開始した生成、復習シート）は、最大3件まで同時に実行します。それ以降の処理は順番を待ち、コースは実行中の生成の完了を待たずに開きます。

### 適応型学習

- **クイズの統計**：問題ごとの回答履歴と正答率を追跡
- **クイズの復習**：元のクイズの資料に基づき、苦手な概念に焦点を当てた新しい問題を5-10問生成します（モデレーションのチェックも同じ資料を対象にします）
- **学習指示の検出**：復習の指示（「次のことができれば、この授業を理解できている……」など）を検出し、対応するテキスト生成機能（復習シート、フラッシュカード、クイズ、穴埋め問題）で優先します。モデレーションが有効な場合、検出は資料のチェック完了を待ち、安全と判断された資料だけを読み取ります。指示には元の資料の一覧を保持します。そのうち1つでも問題が報告されると、指示は表示も適用もされなくなり、1つでも削除されると指示も削除されます。この処理の費用も計上されます
### 安全性とペアレンタルコントロール

- **4つの年齢層**：子ども（≤10歳）、青少年（11-15）、学生（16-25）、成人（26+）
- **コンテンツのモデレーション**：`mistral-moderation-2603`（Mistral Moderation 2）では11のカテゴリーを利用でき、新しい子ども／青少年のプロフィールでは6つを既定でブロック（`sexual`、`hate_and_discrimination`、`violence_and_threats`、`criminal`、`selfharm`、`jailbreaking`。`criminal`は、歴史を含む50レッスンでの測定で誤検知が一度もなかったことを確認して追加）。カテゴリーは設定でプロフィールごとにカスタマイズ可能。Moderation 2では従来の「危険なコンテンツ」カテゴリーが`dangerous` + `criminal`に分割された（既存のプロフィールは自動移行され、ブロック対象のカテゴリーはインポート済みのソースにも適用される）。既定の安全措置：モデルの応答からブロック対象のカテゴリーを確認できない場合、コンテンツは拒否される（「モデレーションを利用できません」）。モデレーションが有効な場合、生成とチャットの両方で、問題が報告されたソース、確認に失敗したソース、確認中のソースを除外する。一度も確認されていないソース（モデレーション無効時にインポートされたもの、またはプロフィールに紐づけられた旧プロジェクトのもの）は使用前に確認される。再起動で中断されたモデレーションは、サーバーのキーで実行可能なら起動時に再開される。それ以外の場合は、エラーになったモデレーションと同様に、プロジェクトを開いたとき、または次回の生成時に再開される。「再確認」ボタンで必要に応じて確認を再実行できる。モデレーションが有効な場合、ソースが安全と判断されるまで、その内容（プレビュー、テキスト、元の文書）は子どもに表示されない。保護者はPINを入力すると、1回限り閲覧できる。音声クイズの口頭回答は、正誤判定の前にモデレーションされる。日付付きIDを`helpers/moderation-model.ts`に固定：非推奨のエイリアス`-latest`は、APIの一覧に表示されなくなった。
- **保護者用PIN**：SHA-256ハッシュ。15歳未満のプロフィールでは必須。誤ったコードの入力は、IPアドレスごとに15分間で最大10回（429 `rate_limited`）。本番環境へのデプロイでは、ソルト付きの低速ハッシュ（Argon2id、bcrypt）を用意する。
- **サーバーデータ**：`/output`で公開するのはプロジェクトのメディア（音声、画像、インポートしたファイル）のみ。`profiles.json`、`config.json`、`projects.json`、`project.json`は一切配信しない
- **チャットの制限**：16歳未満ではAIチャットが既定で無効。保護者が有効にできる

### マルチプロフィールシステム

- 名前、年齢、アバター、言語設定を持つ複数のプロフィール
- **プロフィールごとの音声**（`Profile.mistralVoices?: { host?, guest? }` — 各役割は任意）— 子どもごとにポッドキャスト／音声クイズ用の音声の組み合わせを設定できる
- **プロフィールごとのテーマ**（`Profile.theme: 'dark' | 'light'`）— プロフィールの変更時に自動で切り替わり、バックエンドに保存される
- `profileId`でプロジェクトをプロフィールに紐づける。プロフィールのない旧プロジェクトは、最初に開いたプロフィールに紐づけられ、そのプロフィールに従ってモデレーションされる
- 連鎖削除：プロフィールを削除すると、そのプロフィールのプロジェクトがすべて削除される

### APIコストの追跡

課金対象のMistral呼び出し（チャット、OCR、STT、TTS、エージェント）は、指示の検出と音声クイズの口頭回答も含め、ユーザーに**透明性のある**€単位の見積もりを提供するために計測される。無料のモデレーションは集計しない。エージェントのツール料金も含まれる：ウェブ検索1回あたり0,03 $、画像生成1枚あたり0,10 $（Mistralの料金）。さらに、これらのツールが生成するトークンは、エージェントのモデルの入力料金で見積もりに加算する。

- **正とする情報源**：`helpers/pricing.ts` — モデルのプレフィックスごとの`MODEL_PRICING`（例：`mistral-large` → 入力0.5 €/Mトークン、出力1.5 €/Mトークン）、定期的な再スクレイピング用のMistralドキュメントURLを含む`PRICING_SOURCES`
- **対応する単位**：`tokens`、`characters`（TTS）、`pages`（OCR）、`audio-seconds`（STT）— `helpers/cost-calc.ts`で換算を制御
- **計測の処理経路**：`helpers/tracked-client.ts`（Mistralクライアントをラップ）→ `helpers/usage-context.ts`（AsyncLocalStorage）→ `helpers/cost-calc.ts` → `helpers/cost-persist.ts` → `helpers/cost-middleware.ts`（HTTPレスポンスに挿入）
- **ユーザーインターフェース**：生成ごと（`src/partials/cost-badge-gen.html`）、ソースごと（`cost-badge-src.html`）のコストバッジ、ダッシュボードの累計（`Project.totalCost`）
- **エンドポイント**：`/generate/*`と`/sources/*`のレスポンスは、返却するオブジェクト（`Generation` / `Source`）に`estimatedCost`、`usage`、`costBreakdown`を付加する。`POST /generate/route`はルーティングのみのコストを示す`costDelta: number`フィールドを追加する。`POST /detect-consigne`（`{consigne, costDelta}`）と口頭回答の正誤判定も、それぞれの`costDelta`を返す。`GET /projects/:pid`は、`totalCost`（`costLog[]`から計算した合計）を付加したプロジェクトと完全な履歴を返す

### TTS（Mistral Voxtral）とカスタム音声

- **Mistral Voxtral TTS**：既定は**Voxtral TTS**（`voxtral-mini-tts-2603`）。**Voxtral TTS 3**（`voxtral-mini-tts-3-0`、Mistralのプレビュー版、より多くの言語でネイティブ音声に対応）を設定から選択可能。音声合成は100% Mistralで、追加のキーは不要。選択したモデルが受け付ける音声のみ表示する：Voxtral TTSはVoxtral 3で追加された音声を受け付けない
- **カスタム音声**：保護者はMistral Voices APIで音声サンプルから独自の音声を作成し、ホスト／ゲストの役割に割り当てられる。ポッドキャストと音声クイズが保護者の声で読み上げられ、子どもがより没入できる体験になる
- 設定可能な2つの音声の役割：**ホスト**（メインナレーター）と**ゲスト**（ポッドキャストの2人目の声）
- 設定でMistral音声の全カタログを利用でき、言語で絞り込み可能
- 再生（学習シート、ポッドキャスト、書き取りの単語）は、その画面を離れると一時停止し、停止した位置から再開する
- フラッシュカードの読み上げ音声は、初回再生時に作成して生成結果に保存する。再び開くたびに再作成や再課金はされない
- ソースのマーカー（`[Source N]`）は読み上げない

### 国際化

- インターフェースは9言語に対応：fr、en、es、pt、it、nl、de、hi、ar
- AIプロンプトは15言語に対応（fr、en、es、de、it、pt、nl、ja、zh、ko、ar、hi、pl、ro、sv）
- プロフィールごとに言語を設定可能

> **注**：TTSプロバイダーはMistral Voxtral TTSのみ。`MISTRAL_API_KEY`以外に追加のキーは不要。

> **ユーザーが入力するAPIキー**：`MISTRAL_API_KEY`は**任意**になった。未設定でもアプリは起動し、各ユーザーにインターフェースで**自分のMistralキー**を入力するよう促す。キーは**ブラウザーに保存**され（セキュアコンテキストでWeb Crypto + IndexedDBにより暗号化）、リクエストごとに送信される。**サーバーには一切永続保存されない**。優先順位：プロフィールのキー > ブラウザーのグローバルキー > `MISTRAL_API_KEY`（環境変数）。`EUREKAI_REQUIRE_USER_KEY=true`を設定すると、各ユーザーにキーの入力を必須にできる（環境変数のキーは事前読み込みのみに使用される）。

> **ローカルHTTPS（タブレット／LAN）**：`localhost`はすでにセキュアコンテキストである。LAN経由（タブレット）でアクセスするには、ローカル証明書を生成してHTTPSを有効にする。これにより、ブラウザーは保存するキーを暗号化でき、キーは転送中も暗号化される：
> ```bash
> ./scripts/gen-cert.sh 192.168.1.42   # mkcert si dispo, sinon openssl self-signed
> export HTTPS_KEY=certs/key.pem HTTPS_CERT=certs/cert.pem
> npm run dev                          # Express + Vite en HTTPS
> ```

### 環境変数

| 変数 | 必須 | 既定値 | 役割 |
|---|---|---|---|
| `MISTRAL_API_KEY` | 任意 | — | Mistral APIキー（チャット、OCR、STT、Voxtral TTS、エージェント、モデレーション）。未設定の場合、ユーザーがアプリでキーを入力する（ブラウザーに保存し、サーバーには保存しない） |
| `EUREKAI_REQUIRE_USER_KEY` | 任意 | `false` | `true` → AIリクエストで`MISTRAL_API_KEY`へのフォールバックを無効にする（各ユーザーが必ず自分のキーを入力する必要がある）。外部公開するインスタンスで有用 |
| `HTTPS_KEY` / `HTTPS_CERT` | 任意 | — | TLSキー／証明書のパス（`scripts/gen-cert.sh`を参照）→ ExpressとViteがHTTPSで配信する（LAN／タブレットでのセキュアコンテキスト） |
| `PORT` | 任意 | `3000` | ExpressバックエンドのHTTPポート |
| `NODE_ENV` | 任意 | `development` | `production`の場合 → Expressが`dist/`からフロントエンドを配信（それ以外は`public/`） |
| `SONAR_TOKEN` | CIでは任意 | — | GitHub ActionsのSonarCloudワークフローでのみ使用 |

### テスト、コード品質、コントリビューション

```bash
npm test                # vitest (déclenche pretest : typecheck + lint:complexity + lint:ci + lint:deadcode)
npm run test:coverage   # couverture vitest
npm run lint            # ESLint + typescript-eslint + sonarjs

npm run security        # Opengrep (SAST local) — bloque sur finding ERROR
```

**Gitフック（Husky）**：`pre-commit`は`scripts/pre-commit-fast.sh`（競合、大容量ファイル、shellcheck）、`lint-staged`、`npm test`を順に実行する。`pre-push`は、まずブロッキングチェック`npm audit`（間接依存も含め、依存関係に`critical`レベルの脆弱性があればブロック。`scripts/audit-verdict.mjs`を参照）を実行し、続いて`npm run security`を実行する。各フックは、いずれかのステップが失敗するとコミット／プッシュをブロックする。

**外部ツール（アプリケーションの起動には任意、`pretest`と`npm run security`には必須）**：

```bash
# Lizard (Python) pour lint:complexity (CCN > 8 sur l'allowlist)
pipx install lizard          # ou : pipx run lizard

# Opengrep (binaire standalone ~40 Mo) pour npm run security
./scripts/install-opengrep.sh   # installe dans ~/.local/bin/
```

これらのツールがない場合、`npm test`は`pretest`で失敗し（lizardが未導入）、`npm run security`も失敗する（opengrepが未導入）。そのため、huskyフックがコミット／プッシュをブロックする。

## アーキテクチャ上の決定

| 決定 | 理由 |
|---|---|
| **React/VueよりAlpine.jsを採用** | 最小限のリソース使用量で、ViteでコンパイルしたTypeScriptによる軽量なリアクティビティを実現。スピードが重要なハッカソンに最適。 |
| **JSONファイルによる永続化** | 依存関係がなく、即座に起動。データベースの設定が不要で、起動すればすぐに使える。 |
| **Vite + Handlebars** | 高速な開発用HMR、コードを整理するHTMLパーシャル、Tailwind JITを組み合わせ、それぞれの長所を活用。 |
| **プロンプトの一元管理** | すべてのAIプロンプトを `prompts.ts` に集約し、反復改善、テスト、言語や年齢層に応じた調整を容易にする。 |
| **複数の生成データに対応するシステム** | 各生成データは固有のIDを持つ独立したオブジェクトで、コースごとに複数のシートやクイズなどを作成できる。 |
| **年齢に応じたプロンプト** | 4つの年齢層ごとに語彙、複雑さ、口調を調整し、同じ内容でも学習者に応じた教え方を実現。 |
| **エージェントを利用する機能** | 画像生成とウェブ検索には一時的なMistralエージェントを使用し、自動クリーンアップでライフサイクルを適切に管理。 |
| **URLのインテリジェントなスクレイピング** | 1つの入力欄でURLとキーワードの混在に対応。URLはReadability（静的ページ）でスクレイピングし、必要に応じてLightpanda（JS/SPAページ）にフォールバック。キーワードはMistralのweb_searchエージェントを起動。各結果から独立したソースを作成。 |
| **100% MistralのTTS** | Mistral Voxtral TTS（`MISTRAL_API_KEY` 以外の追加キーは不要）— 音声合成を費用集計と、言語に応じた音声選択の仕組みに統合。 |
